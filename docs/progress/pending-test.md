# 待测试

## 人物表情板

- 项目资产新增“人物表情板”：完整板必须归属 Character 或具体 Look；关键近景使用的干净单状态图片以完整表情板为父级。工作台资产筛选、版本采用、侧栏素材和 Canvas Agent 均识别新类型。
- 故事板阶段的 `expression` 只接受完整表情板，视频阶段只接受其单状态子参考；绑定、运行预览和冻结快照会拒绝错阶段、错父级、错媒体以及借其他 role 绕过。
- AI 漫剧完整制作 Skill 已从规范源生成至 v11，定义 5–8 个脸部为主且兼顾肩颈/呼吸/重心的状态、首次关键特写使用规则、H3 九图优先级及板式泄漏 QA。后端全量测试、前端 TypeScript、31 项 Agent/绑定投影测试、5 个 Skill 校验及 78 文件同步校验通过。
- 待人工验证：在正式项目创建并采用一张完整表情板和一个单状态子参考，分别绑定故事板与视频，确认 UI 预览顺序、错误提示及真实 H3 特写中微表情可读，同时无宫格、标签、白底或其他状态泄漏。本轮未提交付费媒体生成。

## 漫剧提示词编辑区

- 漫剧工作台的故事板生成提示词与完整视频提示词默认高度统一增至 320px，长提示词进入页面即可显示更多正文；编辑区仍支持上下拖动，并允许最大扩展至 768px。

## 漫剧最新生成结果

- 故事板和视频的新运行完成并保存真实媒体后，都会自动成为当前采用结果并投影回对应画布节点；旧运行和旧媒体继续保留，可在工作台重新切换采用。

## 画布入口与 Codex Agent 后台重连

- 从项目卡片进入分集画布时不再自动弹出漫剧工作台；仍可通过画布顶部按钮或双击 Clip 组按需打开。
- 浏览器最小化、切换软件或后台节流导致 SSE 短暂中断时，连接状态切换为“连接中”并保留 EventSource 自动重连；恢复页面后持续重试注册当前画布工具，单次 `/connect` 失败也不会销毁客户端或要求手动点击重连。
- Canvas Agent 服务端对事件流断开提供 60 秒会话宽限期，期间保留 Codex 子进程、工具和画布注册；同一页面恢复事件流会复用原会话，只有持续断开超过宽限期才清理资源。
- 本地地址指向其他网页服务时，不再显示 JSON 解析异常，而是明确提示核对 Canvas Agent 启动输出中的端口。

## H3 最终提示词内部说明清理

## 画布一键整理

- 左下角“整理画布”按钮与 `Alt+Shift+F` 现在按图片、全景图、文本、配置、视频、音频、导演台和普通组分类分列，每类节点在自己的列内纵向排列；正式 Clip 的故事板/视频组统一位于最右列，并按 `C01/01` 等标题编号自然升序排列，无编号标题保留原画布顺序。
- Clip 引用资产不再附着在 Clip 复合布局上，而是按自身媒体类型进入资产列；这只调整画布投影和旧引用节点的分组归属，不改变资产版本、绑定连线或输入顺序。
- 整理先以未保存预览展示并自动适配视口；浮层提供“还原 / 保留”，还原恢复原布局和视口，保留才写入画布并形成一条可撤销历史。
- 整理只改变节点坐标、正式组尺寸和旧参考节点的分组归属，不改变提示词、生成参数、素材绑定、连线、运行快照或采用记录。布局单测 6 项及 TypeScript 检查通过，待在包含 27 个 Clip 的《万法有息》第 2 集画布人工确认视觉密度与交互。

## 漫剧素材节点跨 Clip 共享

- 同一分集画布内，相同资产版本的图片和视频参考现在复用一个画布级素材节点，可同时连接多个 Clip 的故事板与视频节点；每条连线仍独立保存目标、用途、顺序和 Speaker 信息。
- 单个目标解除绑定只移除自己的绑定连线，不删除共享素材节点或其他 Clip 的连线。语音继续按 Clip、版本和说话者隔离，避免角色声音误复用。
