# 漫剧工作台实施基线

> 历史实施基线：本文记录 2026-09-13 首版决策。当前正式规则已升级为 Infinite Canvas 数据库唯一生产状态、旧 AIDramaWorkbench 只读、托管 `AI 漫剧完整制作` 系统包及统一 Canvas Agent/Codex MCP 工具；以 `pending-test.md` 的 2026-09-14 验收和当前代码为准。

## 已确认边界

- 一部剧一个项目，每集一个正式画布；Clip 对应可折叠节点组。原 ComfyUI 工作台保持独立，不同步、不改写。
- 工作台是同一业务数据的制作视图，画布是节点视图。复用现有素材库、个人素材、上传、存储、渠道和任务，不复制媒体系统。
- 账号等通用功能沿用本项目。暂不建设支付、运营、完整剪辑台、独立 TTS 或画布内专业 Skills。
- Codex 及现有专业 Skills 负责内容。小说原文进入改编与制作拆解；已有剧本直接进入必要拆解，不强制重写。
- 所有页面沿用画布主题。入口位于画布左上角，完整工作台覆盖当前画布，返回保留视口。

## 内容与节点

五个页面为项目、制作流程、制作台、素材库、运行历史。四步制作为剧本与 Clip、准备资产、导演故事板、完整视频提示词。

- 项目保存来源正文、改编蓝图、全局风格；各集保存当前剧本、场次和 Clip 排序。稳定 ID 不跟随展示编号变化。
- Clip 保存实际 Shot、精确对白、时长、声源、摄影与进入/退出状态。场次可跨多个 Clip，故事板格对应同一份 Shot 数据。
- 节点保存生成草稿与参数、真实输入绑定。布局和制作内容分别更新；局部写入携带版本，冲突不能覆盖用户修改。
- 确认拆解后创建 Clip 节点组和制作结构；工作台与节点修改同一内容。自动准备不等于自动付费生成。
- 制作依赖与真实模型输入分别表达。真实输入记录素材 ID、来源、版本、用途和顺序，不根据视觉连线顺序猜测。
- 重新拆解、共享素材替换、结构修复均先预览再选择应用。不自动重排手工布局或重建已移除节点。

## 资产与生成

- 人物拥有多造型，每套正式造型采用完整身份板。人物默认音色可被 Clip 覆盖，仅实际说话者绑定声音。
- 所有正式场景采用完整多视角场景板；所有明确道具独立建档与准备参考。重要状态独立记录，跨集复用固定版本。
- 每个 Clip 一个完整全彩故事板，整板预览加镜头列表。实际镜头数自适应，总时长为镜头合计，不固定八格或十五秒。
- 故事板同时支持定向修改与整板重生成，保留候选；局部修复仍检查未指定区域，用户决定采用。
- 完整提示词可以手改，上游变化仅提示复核。提交不重复追加上游剧本，缺失或超限不得静默丢图、拼图、改模型。
- 图片使用当前配置图片 API；H3 补齐旧工作台多模态绑定，以当前工作流公开输入为准，不改隐藏处理链。
- 参数优先级：节点显式设置、项目显式设置、工作流原值。未设参数不注入固定步数、时长或分辨率。
- 队列入队冻结输入，修改草稿不暂停既有任务；可以继续入队。默认同一 ComfyUI 实例一个在途任务，同一远程图片渠道并发二项，可调整。
- 持久化队列调用既有执行器；已有图片/音频 handler 的 goroutine 不构成重启恢复保障。
- 明确失败手动重试，默认当前草稿并显示差异，另提供原输入重跑。“再抽一次”仅改变历史快照 seed。
- 状态未知先核查不重发；保存失败重试保存。停止批次仅停止后续提交，不全局取消 ComfyUI 队列。
- 未提交取消释放或退回现有预扣额度，已提交不退费；状态未知先查清。无新增充值支付系统。
- 更新输入保留旧采用并标记待复核。节点移除保留历史；Clip 回收站不自动清空；被引用资产归档但保留文件。
- 导出采用媒体与排序清单。缺项默认拦截，用户可明确选择部分导出。采用媒体不能仅依赖浏览器临时 URL。

## 实施顺序

1. 项目与分集接口、事务创建集画布、版本校验和工作台入口。此阶段不冒充制作流程已经可用。
2. Clip/Shot、共享资产版本、四步编辑、节点组、自动连线、Codex 统一业务接口。
3. H3 绑定、持久队列、候选回填/采用、删除恢复、素材包导出。
4. 端到端验收及专业内容人工检查。已完成事项列入 pending-test，未完成保留 todo。

Canvas Agent 工具、Codex MCP 路由和托管专业 Skill 包已完成并通过隔离验证。新生产不得再向旧 8188 工作台写入；ComfyUI 只执行由 Canvas 运行快照编译的请求。当前用户已确认规则优先于旧 Skill 中简单场景/关键道具等不同默认。

## 验收样本与隔离

- 使用已跑通的《万法有息》第一集作为测试副本，读取当时当前正式剧本、Clip/Shot、已采用资产、故事板、实际提示词与采用视频。
- 原工作台、原文件和必剪工程不改写，不导入为持续同步源，不开发通用迁移系统。
- 管理验证覆盖全第一集；另设临时第二集画布，只验证共享和隔离，不虚构第二集剧情。
- 实际生成仅选输入完整的 Clip 隔离重跑；明确发起才提交，不默认整集重跑。结果单独保存，不能覆盖原采用。
- 核对工作台/节点一致性、版本与顺序、并发冲突、入队后修改、防重复提交、未知状态、服务重启、修复/采用/导出。
- 生成允许随机差异，不要求与原片逐帧相同。最终须真实可播放、内容可用、对接准确，并经用户确认，才算首版完成。

## 本轮整体检查结论

方案可以实施，但不能把已有素材 URL 当作完整版本引用，不能把现有后台 goroutine 当作持久队列，不能让漫剧画布因普通云同步关闭而停止保存。普通画布整份 JSON 的保存与删除在涉及正式集画布时需要校验服务端归属，不能信任客户端关联字段。上述工作属于制作数据可靠性的必要适配，不扩大到独立运营平台。

尚未进行新的付费生成或用户最终内容验收；历史样本的可播放与导出通过不等同于新生成质量通过。按已确认边界，明确选择重跑范围后再提交，旧采用保留。
