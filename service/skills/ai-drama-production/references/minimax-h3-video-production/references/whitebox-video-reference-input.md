# H3 白模视频参考输入

只在项目选择 Blender 白模预演且当前 Clip 的连续预演已通过 QA 时读取。本页定义 H3 的任务输入适配，不定义或修改 H3 模型处理主体。

## 参考职责

- `<Picture 1>`：当前 Clip 的完整导演板；控制实际各 Shot 的顺序、覆盖、构图、身份、场景、道具、光线和状态交接。
- `<Video 1>`：同 Clip Blender `*_reference.mp4`；仅控制摄影机路径、工作侧、屏幕左右、空间调度、动作节拍和镜头落点。
- 若两者冲突，先修整板目标 Panel，使其继承白模的摄影合同；不让 H3 在两种镜头设计之间自行选择。

## 默认绑定

项目选择 Blender 白模预演时，该 Clip 唯一通过 QA 的连续 `*_reference.mp4` 必须真实接入 `video_1_frames`，并在提示词绑定 `<Video 1>`。实际各 Shot 的相机、调度、动作和切点都在这条同 Clip 预演时间线中，不按 Shot 拆成多个 Video 槽。视频无法解帧或映射无法验证时，报告真实路线失败。

## 当前输入边界

每次提交前，从当前选中的 H3 UI 工作流重新转换 API 图，并重新查询 live schema。更新后的 Ref2VA 包装节点直接暴露 `video_1_frames`–`video_3_frames` 与对应的 `video_N_audio`：默认只将同 Clip 白模接入 `video_1_frames`，其配对 `video_1_audio` 保持空置，其余 Video 槽省略。白模源 MP4 的解帧方式以该次 UI 图公开输入支路为准，不手工重建历史链或改动封装节点内部。

## 预演文件与标签

- 只接入一个已通过的、不跨场、不含 UI/文字/拼贴的同 Clip Blender `*_reference.mp4`，作为 `<Video 1>`。
- 按当前 H3 能力保证参考时长；当前指南记录为 2–15 秒、同媒体总计不超过 15 秒。短编辑镜头可使用同机位且无第二事件的 2 秒以上容器，再由必剪裁切。
- `subject_definitions` 明确 `<Video 1>` 只控制相机、调度和节拍；在 `detailed_description` 中每次依赖这些内容都紧邻写 `<Video 1>`。
- 写明不继承白模代理形体、材质、颜色、标签、UI 或源音频，也不把它当作正式美术或额外 Picture。

## 采用前检查

确认实际执行图同时存在：白模文件路径、一个 `video_N_frames` 的实际输入、匹配的 `<Video N>` 提示词绑定、未误接白模源音频，以及输出目录的实际参考文件副本。生成后按白模检查工作侧、主运镜路径、屏幕锚点、人物/道具调度、动作节拍和落点；最终身份、美术、道具和声音仍按完整分镜导演板与各自资产验收。
