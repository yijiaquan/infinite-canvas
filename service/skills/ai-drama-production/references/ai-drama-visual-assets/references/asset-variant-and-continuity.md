# 资产复用、版本与镜头连续性

用这份判断在制作拆解阶段决定复用还是新建。它只帮助选择当前资产和补全 H3 Shot 边界，不建立资产锁、候选池或连续性账本。

## 三个问题

1. 去掉瞬时动作后，它还是同一个人物、地点或物件吗？
2. 这项变化会持续、再次出现，或需要下游精确选择参考吗？
3. 如果只写在本 Shot 的开头/结尾状态，是否已足够？

| 结果 | 何时使用 |
|---|---|
| `reuse` | 现有身份/Look/View/状态仍能准确覆盖。 |
| `new_variant` | 同一主体出现持续且可复用的 Look、场景 View 或道具状态变化。 |
| `new_asset` | 真的是不同人物、独立空间地理，或需独立追踪的物件。 |
| `shot_state` | 只在一个 Shot 或短暂动作中成立，写入开头/结尾状态，不生成资产。 |

## 常见判断

- 人物：持续换装、伤势、伪装、年龄阶段或变形是新 Look；表情、姿势、视线、景别不是。
- 场景：门内/门外、正反打另一侧、独立房间/走廊分区，或关键地标不再可见但仍需保持地理时，建立当前 `Location + View`。不得用文字猜测未建立的另一侧空间。
- 同一 View：仅人物动作、视线或临时手位变化时复用 current View；若背景事实需要稳定，后续分镜导演板引用已采用的同 View continuity reference 并只声明允许变化，不为它新建场景或 View，也不让该参考锁死各 Panel 的构图与机位。
- 道具：跨镜持续的持有人、开闭、损坏、内容物、文字、数量或位置变化是状态；画面左右位置、抬起的一瞬通常只是 Shot 状态。

场景主图和每个可复用 View 必须使用不同稳定 ID：`LOC-CELL-MASTER`、`LOC-CELL-VIEW-DOOR-IN`、`LOC-CELL-VIEW-DOOR-OUT`。同一 View 的返修沿用该 View ID 并升版本；新角度不可复用主图 ID，否则会覆盖索引的 current 指向。

## 相邻镜最小交接

只写会发生变化或下游需要选择的项目：Look/伤势、Location + View/主光、关键道具的持有人与状态、人物朝向/屏幕方向、动作未完成部分、对白尾音/环境声边界。

相邻 H3 Shot 的前后状态不一致时，先查剧本和分镜导演板的相邻 Panel 是否真的安排了变化。没有原因就修目标 Panel/拆解，不让提示词偷偷“补过去”。
