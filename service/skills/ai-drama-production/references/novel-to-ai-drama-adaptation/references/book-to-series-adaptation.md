# 全书小说到系列改编

只在建立改编简报或全书改编蓝图时读取。

## 选材顺序

1. 确认来源路线、可用范围和不能复制的表达。
2. 阅读全书总览、分卷大纲、章节目录和已有摘要，确定故事弧；只对候选故事弧精读原文。
3. 为每条重要小说线做一个处理：`保留 / 合并 / 重排 / 删除 / 旁白承载`。
4. 把保留内容落到改编后的角色目标、阻力、选择、代价和可见结果中。

## 小说表达的可拍转换

| 小说载体 | 改编优先方式 |
| --- | --- |
| 内心判断或恐惧 | 选择、回避、身体任务、关系反应、空间或声音变化。 |
| 大段设定说明 | 只保留会改变当前选择的规则，用道具、对手、后果或必要旁白承载。 |
| 长时间跳跃 | 用进入状态、离开状态与结果明确的场次切换。 |
| 叙述者总结 | 改为发生中的动作、反应或简短画外信息。 |
| 复杂人物线 | 合并功能相同的人物，保留能制造独特选择和代价的关系。 |

保真不等于逐句复制。改编蓝图必须保留主人确认的核心命题、人物变化和关键结果，同时形成独立、可生产的戏剧表达。

## 全书蓝图最小项

- 改编命题与目标观众；
- 整书核心问题和最终改变；
- 各季/故事弧的起始压力、转折、局部结果、继承压力；
- 改编后的人物功能、关系、世界规则和信息权限；
- 改编取舍及对应小说证据；
- 首季范围及其结尾为何足以形成局部完成。
