# 小说/IP 到分集 AI 漫剧的写作方法

## 1. 来源与权利分流

这是一道生产门禁，不是法律意见。对外部小说先记录作品名、作者、出版/连载状态、具体版本、译者、来源和拟用范围，再选择路线。

| 路线 | 可以做 | 不可以默认做 |
| --- | --- | --- |
| 原创 | 从主人给出的点子建立全新世界、角色和剧情 | 把已知作品的独特表达换名复刻 |
| 已授权改编 | 在授权的媒介、地域、期限、平台和商业范围内改编 | 超出合同范围或默认拥有续作、衍生、翻译权 |
| 已核验公共领域 | 使用已进入公共领域的原作元素 | 默认使用仍受保护的现代译本、插画、封面、录音或后续改编 |
| 仅灵感参考 | 借鉴题材、母题、类型机制、抽象氛围或观众需求 | 沿用独特角色、名称、世界设定、连续事件、对白、标志性场面或结局表达 |
| 未解决 | 做书目信息和权利调查 | 进入衍生故事、资产或发布生产 |

《中华人民共和国著作权法》把改编纳入著作权权利体系，并对使用改编作品及原作品规定许可边界。生产时以[中国人大网公布的现行文本](https://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html)为权利核验起点，同时核对实际权利人、合同和拟发布地区。

只给小说名时：

1. 先核对作者、版本和同名作品，避免对象错误。
2. 只使用合法可访问的书目信息、主人提供且有使用依据的文本，以及可合法引用的研究资料。
3. 不从盗版站获取全文，不根据章节梗概重建原文，不把影视改编当作小说原文。
4. 若走“仅灵感参考”，建立原创化差异表：人物关系、世界规则、核心因果、升级路径、标志场面、反转和结局都必须形成新的表达；改名不是原创化。

## 2. 六层故事产物

按层级推进，后层不得悄悄修改前层：

1. **改编命题**：这次为什么讲、给谁看、保留什么抽象价值、创造什么新表达。
2. **系列圣经**：世界规则、人物功能与弧线、季问题、集数/时长、连续性和揭示账本。
3. **分集卡**：每集 Hook、目标、阻力、升级、转折、回报、结尾状态和下一集悬念。
4. **单集小说文本**：以可阅读的连续叙事证明情节、人物和情绪成立。
5. **制作剧本**：Scene/Beat ID、可见动作、对白、旁白、声音、时间、进出场状态和制作意图。
6. **生产拆解**：角色/Look/State、场景/View、道具/State、声音、连续性变化和资产依赖。

## 3. 单集剧情推敲清单

在进入生产拆解前逐项检查：

- 因果：每个重大结果是否有可见原因；巧合是否只制造问题而不代替解决。
- 动机：人物此刻为什么行动；目标、风险和选择是否可辨认。
- 信息：观众知道什么、角色知道什么；揭示是否过早、重复或缺失。
- 升级：每个 Beat 是否改变信息、情绪、权力、危险或关系。
- 铺垫/回收：重要道具、能力、规则和反转是否有充分准备与兑现。
- 连续性：时间、空间、人物状态、服装、伤势、持有物、人数和前集结尾是否一致。
- 分集：开头承诺是否明确；本集是否有可交付回报；悬念是否来自未完成目标而非任意截断。
- 对白：角色声音是否区分；对白是否承担冲突/信息/关系变化，而不是复述画面。
- 可视化：关键情节是否能被镜头、声音或表演表达；不可视内容是否需要旁白或改写。
- 可生产性：动作、人数、场景切换和几何接触是否与预算、模型能力和目标时长匹配。

## 4. 审阅与生产衔接

- 内部可以比较多个大纲、正文和剧本版本，但只把一个带变化摘要的候选交给主人阅读。
- 主人同意当前单集故事和制作剧本后直接进入生产拆解；只在紧凑项目状态记录采用版本，不增加会议、表单或额外步骤。
- 角色、场景、道具和完整分镜导演板由内部内容 QA 选择；普通结果不逐项打断主人。
- 将连续 Beat 聚合为同场、连续时间的 Clip，使用当前身份、场景和关键道具参考一次生成一张完整导演板；不要逐 Shot 生图，也不要把多张散图事后拼成整板。
- 下游发现真实剧情、动机或对白含义问题时返回新剧本版本；普通画面、提示词或技术问题只返修对应媒体。
