# 高密度打斗、技能与能力调度

仅当 Clip 包含徒手、武器、追逃中的直接冲突、法术、异能、怪物能力、巨物或会改变战术关系的技能效果时读取。本页以“连续因果攻防”作为打斗主方法：先导演一整段战斗，再将已成立的攻防分配给分镜导演板和 H3；不以招式、特效或运镜词堆砌代替动作逻辑。

## 使用边界

- 正常 H3 打斗路线仍是：一个同场、同时间、实际时长的 Clip → 一张完整全彩正式导演板 → 一次 Ref2VA 请求。分镜是同一场连续攻防的编辑覆盖，不是多次互不相干的生成。
- 高密度模式适合双方事实、空间和主要目标已清楚，且对白没有占满动作容量的 Clip。对白、多人复杂交互、跨场、地理变化或一个动作链无法看清时，沿真实剪辑边界拆到下一个 Clip，不把所有情节压进一段。
- 本页只决定动作编舞、镜头切点和连续性。H3 最终文本仍使用当前本地六段结构、中文导演正文和正向描述；不导入参考包的 `BUNNY` 触发词、英文双稿、固定外部 Skill 或“默认无对白”限制。只有主人明确指定当前模型需要某个触发词时才使用它。
- 一个 **Panel / 内部 Shot** 只完成一轮可读战术变化；一个 Clip 可以通过实际各 Panel 串成高密度连续攻防。任何 Panel 的结尾必须已经触发下一轮动作。

## 先建战斗事实与载体

先按以下优先级建立 A / B（必要时再加受控群像）的事实：用户明确设定 → 参考图可见事实 → 当前已采用资产 → 保持连续性所需的最小补全 → 导演原创。每个主体至少记录：

- 身份、体型、服装、可见装备与当前伤势；
- 战斗目标、开场区域、画面左右、朝向、重心与可用通道；
- 武器/法器/能力的种类、数量、持有人、手位、尺寸、来源与当前状态；
- 不能新增、消失、复制、换手或无因改变的事实。

选择与资产相符的主战斗载体，再设计攻防；不同载体不能套同一套动作语汇：

| 载体 | 可读动作重点 | 必须看见的反馈 |
| --- | --- | --- |
| 刃器 | 斩、刺、格、拨、压、绕、滑刃 | 刃线、偏转、切口或受力退让 |
| 长柄 | 中线压迫、刺击、挑击、横扫、贴身后受限 | 距离优势、杆身惯性、回收时间 |
| 钝器 | 抡、砸、压、推、撞 | 重量、塌陷/震动、明显击退 |
| 徒手 | 拳肘膝腿、控臂、卸力、贴身切入、翻摔 | 重心、抓地、身体受力与位置交换 |
| 远程 | 瞄准、发射、规避、遮挡、拦截 | 清楚路径、目标、掩体和命中后果 |
| 法术/异能 | 施放、牵引、偏转、束缚、局部强化、环境操控 | 可见来源、路径、目标、范围与残留 |
| 生物/巨物/机械 | 基于翅翼、足肢、关节、推进器、轮组或机械臂的行动 | 结构、惯性、抓地/升力/传动与尺度 |

徒手面对刃器时，以切线、贴身、控住非锋利部位、环境借力或闪避处理威胁；不能写成裸手硬接锋刃。能力效果必须来自已知身体部位、法器、机械结构或已建立环境装置，不能以无来源特效遮挡攻防。

## 连续攻防脊柱

先写 Clip 级因果，不先写多条孤立招式。下表是战术功能示例，不是固定镜头数或必选顺序；按实际剧情选择、合并或扩展，并为每镜给出自然时长。胜负不必强行在本段结尾决定。

| Panel | 战斗阶段 | 本格的可读任务 | 必须交给下一格的状态 |
| --- | --- | --- | --- |
| P1 | 即时威胁 | A 抢位、压缩距离或发动明确第一攻击线；开场就有真实危险 | A/B 的距离、方向、重心、武器/能力起点 |
| P2 | 首次完整应对 | B 格挡、闪避、卸力、偏转或借地形回应；第一次接触/错失可读 | 受力方向、武器偏移、脚步或通道变化 |
| P3 | 余势与位移 | 从上一击的滑退、错身、追击或失衡继续，不复位 | 新位置、高度/支撑面、速度和下一攻击窗口 |
| P4 | 换轴或首次命中 | 用已建立的台阶、门框、栏杆、残墙或移动能力改变攻击线；出现清楚结果 | 命中/擦碰后的伤势、道具状态或环境后果 |
| P5 | 技术交换 | 一方利用前一动作留下的空隙逼近、拆线、控臂、切角或反震 | 优势正在转移的证据与双方身体几何 |
| P6 | 明确逆转 | 原被压制方通过已有资产夺回位置、路线或攻击轴 | 新占优者、被迫退让者、可继承的障碍/危险区 |
| P7 | 追击与封锁 | 占优者封路；另一方通过正在运动的环境或自身既有能力改变路径 | 最后一轮可读防御/闪避和终局线路 |
| 末格 | 结果或进行中切出 | 已指定胜负则呈现命中后的余势与可见落点；未指定胜负则保留在攻击、追击、滑行、卸力或环境连锁中 | 下一 Clip 可继承的位置、注意力、道具和声场 |

对于明确胜负，末格 可采用“逼出预判 → 改变攻击轴 → 命中后的余势”三拍，但三拍必须来自前七格已建立的重心、距离和资产，不能突然新增形态、武器或能力。未指定胜负时，不能为了结尾完整而擅自缴械、跪地、摆姿或静止。

10 秒及以内的明确短任务可压缩为四段：即时抢攻 → 接触后变线 → 持续追击与攻守转换 → 进行中的切出或指定结果。短片不套用完整终局，也不强制分镜；按当前选定模式和真实时长重算 Panel/Shot 数。

## 每格的动作、物理与连续性合同

每个 Panel / Shot 都要写清以下六项，并把结尾真实交接到下一格：

1. **行动主导者与目的**：谁试图取得距离、路线、武器、掩体或攻击窗口。
2. **开场几何**：画面左右、距离、朝向、重心、空闲手、持物和能力源头。
3. **一轮主行动**：触发 → 可见准备 → 动作中间态 → 对手/环境的一次受控响应。
4. **接触与受力**：攻击线、接触点或错失、反震/形变、沿力线的位移。
5. **环境结果**：尘土、碎石、栏杆、墙体、桌面、雨雪、烟雾或装置只在真实受力时响应；若其改变下一路线、遮挡、支撑或优势，必须被下一格继承。
6. **结束状态**：人物位置、身体朝向、脚下支撑、伤势、装备归属、能力残留、声场和下一行动触发。

关键攻防交换可包含一条连续攻击线上的多次短接触，但不能在一格同时塞入多轮连招、多人闪避、范围爆炸、落地、追击和反杀。角色不会在切镜后无因复位；武器不会无因消失、复制、换手、变形或改变数量。未声明的门窗、设备、主光、地标和人群簇同样不随打斗漂移。

## 镜头与场面调度

- 每次切镜必须由攻击线、接触/错失、位移、遮挡、环境受力或优势转换触发。切镜只改变观看角度，不重置人物状态。
- 每格一个主摄影行为，默认稳定观察或平滑受控的推进、后拉、横移、跟拍、环绕、过肩重取景。战斗速度与力度来自人物运动、接触和后果，不默认来自摄影机震动。只有明确需要摄影机表现冲击后的失衡时才使用短促受力震动、甩镜或滚转，并写清触发、结束及恢复稳定后看清结果的落点；普通镜头不会继承该例外。
- P1–末格 共同形成覆盖变化：建立威胁 → 看清接触 → 看清位移 → 改变工作侧/高度 → 看清技术交换 → 读取逆转 → 追踪封锁 → 落到结果或仍在进行的方向。相邻格通常让 `Camera / Body / Information` 至少两项变化。
- 继续服从当前场景的 Camera Zone、180°轴、屏幕方向、3–5 个可见锚点和角色/群像区域。机位可以在合法工作侧内改变焦段、距离、高度、前景与构图；空间稳定不等于固定摄像头。
- 群战先选择一条焦点攻防关系。其他具名角色和 `Crowd-*` 簇只维持已声明的区域、朝向、密度和通道，除非某格明确认领它们的重排。

## 法术、技能与范围效果

把每个非实体效果写成：

`来源 → 形态/材质 → 方向/路径 → 目标/范围 → 可见后果 → 残留或消散`

施放格保留来源和起势；飞行/位移格只跟随一条已建立的路径；命中格只呈现一个目标或范围的受力/状态改变。经常复用、必须一眼识别的能力可按需有独立 `reference_frame` 固定其轮廓、材质与色彩；一次性的火、尘或冲击波只是 Shot 状态。效果不能顺便改写身份、服装、场景拓扑、未声明设备或主光。

## 声音、参考与 H3 编译

- 声音顺序跟随可见动作：移动/脚步 → 破风或能量起势 → 真实材质接触 → 身体受力 → 环境响应 → 再加速/落地。每格仍写 `AMB=延续/进入/退出` 与一个空间锚点；打斗不等于把环境底声清零。
- 有对白时，先保证可朗读台词与动作容量。普通连续对白全文只在唯一 owner Shot 的 `<d>` 中出现；确需跨剪时使用相邻 owner span、成对 `<scenetrans>` 与无缝声音说明。其余打斗格只描述发言阶段、口型/身体表现和声桥。沉默角色不上传 Voice 样本。
- 完整分镜正式导演板继续作为规划权威，并作为普通 `<Picture 1>` 进入 Ref2VA，但不接入首帧端口。后续图片连接参战角色完整身份板、当前完整场景板和实际关键武器/法器道具板；能力视觉语言与关系锚点仅在真实风险存在时按职责追加。不上传分镜裁图、单视角派生图、重复图或上一成片尾帧。
- H3 最终提示词以六段结构承载这条时间线。`summary` 概括战斗目的和结尾状态；`detailed_description` 逐 Shot 写完整导演字段；`overall_soundscape` 只写物理声场，不重复可朗读对白；`non_diegetic_music` 默认 `none`，配乐由必剪跨镜处理。

## 打斗 QA 与最小返修

正常速度先看完整 Clip；快速接触、投射或高风险交接再逐秒检查。通过的片段必须让观众读到：

- 谁发起、攻击/能力从哪里来、沿什么方向到达谁/什么范围；
- 每次重要攻防为何发生、如何被应对、造成什么受力/位移/环境后果；
- 人物身份、服装、人数、屏幕方向、相对距离、武器/法器归属、伤势、Location + View、主光与锚点连续；
- 摄影没有遮住唯一主动作，切镜没有复位，声音与接触、施放、命中和环境受力同步；
- 末格 的位置、道具、伤势、能力残留和声场可被下一 Clip 的 P1 继承，或在明确结果后保留余势。

动作/结果不成立归为 `performance_flat`；人物、武器、效果源或空间关系漂移归为 `space_prop_continuity` 或 `asset_reference_drift`；镜头遮挡事件归为 `camera_failure`。先修对应 Panel 的战斗合同、关键参考或摄影职责，再按既有最小返修路线重拍受影响内容；不以更强特效、更多晃镜或静态摆姿掩盖失败。
