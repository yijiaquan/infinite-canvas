# 场面调度与 Shot 职责

只在双人关系、门口进出、道具交接、证据揭示、追逐或多人同框时读取。本页把已批准 Beat 变成可执行的空间关系；它不创建导演板、锁、状态账本或固定切镜公式。

## 一个主变化，只交给一个 Shot

高风险 Shot 在现有制作拆解中额外写四项：

1. **Shot 功能**：`establish`、`primary_action`、`reaction`、`insert` 或 `transition`。
2. **唯一主状态变化**：本 Shot 实际完成什么，例如“门从关到开”“存储卡从林晚手中转到周屿手中”“周屿第一次看清证据”。
3. **行动主导者与受控回应**：谁完成主变化；其余人物只承担一个可读的小反应、受限位置或环境动作。
4. **交接状态**：下一 Shot 必须继承的画面左右、朝向、持物、入口/地标、主光和声音状态。

`establish` 只建立空间、关系或注意力；`primary_action` 是唯一实际完成主变化的 Shot；`reaction` 让人物或环境承接后果；`insert` 让关键手、道具或证据可读；`transition` 用可见位移、中性重建或已采用新 View 合法改变空间关系。每个 Shot 可以包含触发、准备、执行和反应链，但只能有一个不可逆的主要变化。不要把同一动作在正反打、特写和反应镜中重新发生。

## 常见场面调度

### 双人对话 / 对峙

- 需要时先用 `establish` 保住双方距离、入口控制权和轴线；之后只在信息、权力、动作或反应真正变化时新建 Shot，不做每句台词的机械正反打。
- 每个说话者和听者都绑定场内注视目标：写清对方位于其左/右前方、距离和眼线高低，摄影机位于哪一工作侧。近景优先保持三分之二侧脸或越肩关系，双眼落在镜头旁的真实对手位置；不能把“正脸清晰”误写成“看向摄影机”。视线转移必须由道具落下、门响、他人移动或新的信息触发，并写出新目标。
- 只有摄影机明确代表对方双眼的 POV，或剧情是自拍、视频通话、演讲/直面观众时，人物才可接近直视镜头；下一镜必须保持这个 POV 身份，不把普通客观机位混成 POV。
- 说话 Shot 给信息承载者；听者的 `reaction` Shot 只表现其接收、让位、反制准备或选择，不让他同时完成另一件大动作。
- 同一轴线工作侧内，反打画面方向互补。若需要换侧，使用同镜可见跨越、中性重建，或先采用正确的 `Location + View`。
- 权力变化必须能看见：谁占入口、谁退到背景、谁先移动、画面占比或机位高度怎样改变。

### 门口进出

- 门内和门外是不同的 `Location + View`；先让空间入口和人物起始侧可读，再安排穿越。
- “开门”“跨过门槛”“转身回看”是不同的主变化，分别由不同 Shot 承担；不要在每条视频中重复开门或跨门。
- 进入/离开后的 Shot 首先确认新位置、视线、门的最终状态和声场变化。新 View 只能改变已建立地点的机位/朝向，不能凭文字重造另一侧空间。

### 道具递交、夺取与接触

- 先确定持有人、起始手、物件状态和去向。真正交接只在一个 `primary_action` Shot 完成，写清接触点、释放者、接收者和结束归属。
- 前一 Shot 可让人物准备、伸手或犹豫；后一 Shot 用反应或插入确认新持有关系。不要让双方在多个 Panel 里同时紧抓同一小道具。
- 接触几何不可靠时，保留事件结果：拆成“准备 → 一次清楚接触/交接 → 结果/反应”，简化非重点人物和摄影机运动。

### 揭示、追逐与群像

- 揭示按“尚未看到 → 看到 → 接收后果”分配：证据本体、接收反应或新的选择分别在有必要时新建 Shot，不能在同一模糊移动中提前交代全部结果。
- 追逐先保护屏幕移动方向、目的地、阻碍和动作终点；镜头活跃也不得越过未建立的空间或遮住转向/接触结果。
- 同一 Shot 只有一位焦点人物完成决定性动作。响应者只给一个定时反应；背景人物维持受控微动、固定站位或一个群体反应区。

### 多人围堵、绕行与群像站位

三人以上、围堵、队列或群像关系会影响剧情时，在现有制作拆解里写一行紧凑站位合同，不另建场面调度表：

- 每位具名反复角色写 `命名锚点 + 观众画面区域 + 朝向/视线`；他继续使用自己的身份板。匿名背景人员写成 `Crowd-A / Crowd-B` 等簇，并给出人数、区域、整体朝向和密度，不为逐人身份制造参考图。
- 写清入口、可走通道和 3–5 个固定锚点。镜头可以改变景别、机高或观察侧，但未经声明不能把围堵者换边、让人群穿过主角、改变谁控制入口，或把一个簇拆成新的人群。
- 每个 Shot 只允许一项主几何变化：例如“凯恩从操作台左侧绕到门前”“Crowd-A 向后让出半步通道”或“周屿抬手阻止 Crowd-B”。其余人物/簇维持位置或只作受控反应。需要两次重排、真正穿越或人群分裂时，按实际编辑边界使用 `transition` 或新的 `primary_action` Shot。
- 用覆盖让观众读懂变化，而不是让同一远景从头做到尾：先建立谁包围谁、谁控制出口；主动作镜完成一次位移/让位；必要时用反应、近景或插入确认权力/通道已经改变。没有新空间事实就不为凑数切镜。

### 把功能关系投影为可见空间

当保护、施压、观察、阻挡、护送或控制入口/证据/设备会改变行动时，先写有方向关系，再把它翻译成模型能看见的几何：

`A 保护 B → A 位于威胁与 B 之间，身体偏向威胁，留出 B 的后撤线`；
`Crowd-A 施压 A → 缩短距离、统一视线，但保留一条已声明通道`；
`C 控制出口 → C 占据门前行动线，其他人未经本 Shot 可见让位不能穿过`。

同一 Shot 不给同一人物互相矛盾的权限，例如既“堵住出口”又“远离门口”。功能关系改变时，必须由当前 Shot 的可见移动、让位、遮挡或夺取完成，并写进交接状态；不能只在下一镜换一个站位声称权力已变化。

## 信息、分镜 Panel 与声音

- 只有事实会改变人物选择、关系、权力、恐惧或观众理解时，才写 `给出/隐藏 → 载体 → 触发 → 接收后的可见后果`。后果可在当前或下一 Shot 发生，但必须可观察。
- 新场次/集的入口若承担钩子，首个 Shot 优先给主体动作、异常或决定，再按需要建立空间；不是每个 Shot 都重新做一次钩子。Shot 尾按实际用途选择 `resolve`、`edit_point`、`extension_anchor`、`hero_hold` 或 `reveal_punch`。
- 完整分镜导演板中的每个 Panel 只表现所属 Shot 的一个可读瞬间、空间合同、动作阶段和交接基线；H3 在同一 Clip 内完成实际镜头覆盖及其连续动作。反打、反应、插入或新角度优先作为同一整板中的后续 Shot；只有跨场、换时、状态不兼容、内容过载或真实 QA 失败才拆成新的 H3 Clip。
- 每个 Shot 写紧凑声音交接：`AMB=延续/进入/退出 + 可听空间锚点`、实际 Speaker/Line、与可见事件同步的 Foley/SFX 和音乐相对 Cue。相邻同场 Shot 默认继承同一底声及相对距离；门、距离、机器、天气或场景变化才改变声场。

## 空间合同

除既有画面左右、轴线与工作侧外，对话/观察 Shot 还写 `注视目标 → 目标位置/距离/眼线高度 → 摄影机观察位置 → 脸部角度 → 视线转移触发与新目标`。抽象的“看向对方”不能作为可执行眼线。

复杂 Shot 明确：观众画面左右、命名轴线、摄影机工作侧、人物位置/朝向/视线/手与持物、入口/地标/主光位置，以及 3–5 个实际可见固定锚点。默认不越轴；若越轴，通过同镜可见穿越、中性建立镜或已建立的新 View 说明方式。

门窗、设备、显示器、桌面陈设、顶灯、红灯、墙体和主光不得漂移。只有提示词明确写出的动作或状态变化可改变它们；不能用更长提示词弥补错误空间或错误 Panel。

## 返修

导演板阶段已经重复动作、轴线错、门窗换边或道具归属不明，先用原整板和相同参考修目标 Panel，并复核其余格与相邻 Shot。整板正确而 H3 漏做动作、重播动作或镜头失焦时，修该 Shot 的 `performance_arc`、`screen-space contract` 或 `camera_contract`；有自然切点时重拍独立替换 Shot，否则重拍完整 Clip。沿用既有 `space_prop_continuity`、`performance_flat` 或 `camera_failure` 分流，不新增验收账本。
