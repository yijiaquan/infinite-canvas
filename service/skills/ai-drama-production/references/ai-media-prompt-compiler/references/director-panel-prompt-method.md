# 自适应电影导演故事板模板

本页根据用户提供的 LibTV 故事板图片提取版式与信息层级，不声称还原其原始提示词。只吸收“大画面讲戏、底部集中参考与简表”的结构；不复制示例人物、剧情、古风、暖黄色调、五镜数量或三秒均分。

## 制作原则

- 顺序固定：已确认剧本 → current 人物/场景/道具/Look → 完整导演板 → 视频 → 剪辑与审核。
- 先按可见动作、对白自然时长、信息变化和剪辑理由确定实际 N 镜与时段，再组织 Clip；N 与总时长 T 均不固定，不为填格增加镜头或平均分时。
- 更长场次可以先完整规划；当前 H3 已验证单请求使用 2–15 秒范围，执行前按有动机切点拆为各自有整板的 Clips。不能截断对白、压缩行动或只传长故事板的第一页。
- 每张正式整板一次生成为一个完整输出；不先生成独立镜头再拼板。每个主镜头格是一个可读瞬间，动作优先中间态；正文描述仍说明完整起止状态。
- 同一项目统一页眉、编号样式、边线、字体层级和参考区组织，但允许改变格数、行列及关键镜头的画面面积。
- 默认横向制作页；板面画幅可随可读性调整，页眉“成片画幅”写最终视频比例，不把板面长宽比误当视频比例。空间拥挤时先精简不必要参考模块，再按自然切点分成完整板/对应 Clips，不缩小到看不清人脸和动作。
- 正式板采用项目当前全彩 Look；黑白/低饱和草图仅为明确要求的预演版本。
- 故事板只承载视觉镜头规划。剧本对白可以决定 Shot 时长、切点和可见表演，但精确或转述台词、说话者、发言阶段、对白引用 ID 以及任何可朗读角色文本都不得进入故事板图片、板面文字或静态图片生成提示；也不得生成字幕、对白气泡或引号台词。精确对白继续保存在剧本/Shot 合同中，供视频和音频阶段读取。

## 输入与控制域

按 [真实静态参考批次](static-image-reference-batch.md) 传入真实 current 图片，使用实际资产版本结构化绑定和 UI 引用令牌；仅预览/提交编译器生成提供方媒体编号。

- 人物完整身份板：脸、发型、体型、服装、配饰与相对尺度，不固定姿势、表情或画面位置。
- 人物表情板（按需）：正式 `expression` 资产只为指定 Panel 提供状态 ID 对应的微表情、呼吸、肩颈、姿态和重心反应，不改变身份、Look、视线目标、动作阶段或构图；其宫格、标签、文字、白底与其他状态不得进入导演板。
- 场景板与当前 View：地理、出入口、固定陈设、光源、可见锚点，不固定每镜焦距、景别、机高或构图。
- 道具板：形制、尺度、材质、机制。持有、连接、开闭或损坏状态按当前 Shot 继承。
- 当前 Project/Scene Palette：只约束综合色彩；不把示例金色边线或暖光当作项目 Look。
- 原整板（返修时）：提供待编辑主镜头与当前版式；真实修改范围仅为指定格/文字项。
- 既有平面图或 Blender 调度：只解释已建立的地理关系。缺少可信空间源时省略俯视模块，不凭透视图猜造房间背侧。

## 版式标准

1. 顶部窄信息栏：项目名、Clip ID、总时长、成片画幅、题材。信息只出现必要次数，不再放重复“项目总控”块。
2. 主镜头区：占主要面积，全彩电影静帧；按编号从左至右、从上至下。每格画外细信息条仅放 `Panel/Shot ID + 开始–结束时间`。主体图内保持纯故事画面。
3. 底部紧凑参考区：实际相关人物/道具索引、当前场景参考、按需的可信俯视调度；参考图是识别资料，不是后续视频镜头。
4. 底部镜头简表：`镜号 | 时间段 | 可见画面/动作 | 环境/动作声`。最后一列只允许非语言的环境、Foley 与 SFX；不写角色台词、说话者、发言阶段或对白引用 ID。
5. 不强求固定黑底、金线或字体。可用深色中性底、细边框和少量项目兼容强调色，保证画面之间清楚分隔、文字清晰、无重叠。

例如 N=5 可采用上三下二，让后两格稍大；N=3 可采用三格同列或一大两小；N=6 可采用两排三格。它们只是版面示例，不是新的数量规则。每镜有剧情职责，不因格子面积大而自动加时。

## 工作台导演设计字段

每镜在当前 Shot 表中写清：ID、时间、镜头功能、景别/焦段/机高/方向、构图前中后景、人物位置/朝向/视线、身体动作与节奏、场景锚点、主光与材质、运镜、情绪/信息变化、对白/声音、起始状态、结束状态和转场。Shot 表继续保存完整制作事实；送入静态制板的内容必须先投影成不含对白的视觉版本，只保留可见表演、状态变化以及必要的非语言环境/Foley/SFX。不要在故事板中写“无对白”等对白状态标签。

这些完整字段用于制作推理、图片提示和视频编译，不全部印在每格图旁。稳定世界和身份，允许摄影、姿势和表演变化。相邻镜头必须有观看理由，安静停顿也可成立，不用动作噪声代替情绪。

## 返修与采用

查看真实整板：主镜头数、顺序、时间、Beat 覆盖、人物/道具/空间、表演与可读性都必须正确，并确认所有区域都没有角色台词、说话者、发言阶段、对白引用 ID、字幕或对白气泡。底部参考小图不计入 N；不能把多个角度的小索引误验收为多个镜头。画面不能因保留身份而都站着不动，也不能因换镜而换房间。

返修传原整板及相同真实参考，指定目标 Panel/文字项、唯一变化与其余必须保持项；复核所有未改镜头。文字不清时只修文字区域，不能强制套回旧 2×4 排版。现有确定性工具只有支持本次实际版面才使用，否则仍按整板编辑修正。

通过后采用为 `director_board`。H3 使用主镜头区对应的实际 N 镜视觉语义，并按需单独接入必要完整身份板、关键近景单状态表情子参考、场景板和道具板；完整人物表情板不进入 H3。Video/Audio Skills 从同 revision 的剧本与 Shot 合同重新接回精确对白和 Speaker，不能从导演板反推。提示词明确底部资料、表格、编号、边框和纸张排版只是规划参考，最终视频为全幅故事世界，不拍摄参考页或底部缩略图。
