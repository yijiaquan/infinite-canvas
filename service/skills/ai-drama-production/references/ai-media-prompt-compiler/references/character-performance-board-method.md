# Character Performance Board Method

用于主要角色需要重复近景、细腻情绪弧，或身份参考导致表情/姿态僵化时。它生成一张独立的真人电影表演研究板，使用现有 `character_reference` 类型保存为上游静态参考；不替代身份板，也不新增资产类型、审批或固定制作阶段。完整表演板不直接进入 H3。

## 职责分离

- **Identity Board** 只回答“这个人是谁”：脸型、五官比例、年龄、肤色、发型、身体比例、固定 Look、服装与配饰。
- **Performance Board** 只回答“这个角色怎样表演”：眼神、眼睑、眉间、嘴唇、下颌、呼吸、面部肌肉张力，以及与身体重心、肩颈、手臂和躯干的协同。
- 身份板中的中性站姿和表情不是 Shot 的表演指令；表演板不得改脸、改年龄、改发型、改体型、改服装或生成新 Look。

## 三层表演设计

1. **角色表演语言**：写在制作拆解中的长期文字习惯，记录情绪外露程度，以及察觉、怀疑、紧张、恐惧、愤怒、失控与恢复控制时常用的视线、呼吸、肩颈、手部和重心反应。它提供角色差异，但不能把角色锁死在一种反应里。
2. **Clip 表演曲线**：按当前剧情写 `开场状态 → 可见触发 → 上升/压制/爆发/回落 → 结尾残留状态`。强度只在同一角色、同一段落内比较，可以反复升降。
3. **Shot 可见表演**：把当前状态展开成触发、眼球焦点、眼睑、眉间、嘴唇/下颌、呼吸/颈部张力、重心与身体协同，以及结束变化。情绪名称或百分比不能单独成为模型提示词。

## 何时制作

仅在以下情况之一出现时制作：

- 主要角色有多次近景或跨 Shot 的渐进情绪弧；
- 恐怖、悬疑、亲密、审讯等场次依赖克制微表情；
- 实际关键帧或视频连续出现同一中性脸、瞪眼张嘴、只换视线等表演失败；
- 不同 Shot 的角色身体反应语言需要保持同一人物习惯。

普通角色、远景角色或单次简单动作不制作表演板，直接在 Shot 语义中写可见表演。

## 一张板的内容

一次请求生成一张完整表演研究板，背景简洁、无剧情场景、无道具叙事。根据角色和本集需要选择 5–8 个状态；不机械套用固定情绪清单。可使用稳定状态 ID，例如：

- `E01 Neutral Alert`：正常警觉；
- `E02 Notice`：察觉异常；
- `E03 Suspicion`：怀疑与确认；
- `E04 Unease`：克制不安；
- `E05 Startled`：短促受惊；
- `E06 Suppressed Fear`：压制恐惧；
- `E07 Realization`：意识到事实；
- `E08 Frozen Terror`：极端恐惧后的冻结。

每个状态同时展示眼球方向与聚焦距离、上下眼睑张力、眉间与眉峰、嘴唇/下颌/面颊、呼吸和颈部张力，以及肩膀、躯干、手臂和身体重心的对应反应。避免把所有恐惧画成瞪眼、张嘴和夸张后仰；优先体现压抑、否认、确认、克制、突然失控与恢复控制的差异。

## 强度与曲线

表情强度使用相对值 `0–100%` 表示同一角色内部的表演幅度，不是模型参数或跨角色评分。Shot 可以写 `E06 / 60%`，但最终提示词仍需展开成可见肌肉、呼吸和身体行为。

情绪曲线不要求逐 Shot 单调上升。允许 `平静 → 上升 → 突发峰值 → 压回去 → 再次上升 → 最终峰值`，只要每次变化由可见触发和人物选择支撑。

## 提示词职责

静态请求必须声明：current 身份板控制不可变身份与 Look；本表演板只创建同一角色的表演语言；每个状态使用同一脸、发型、身体比例和服装；状态之间只改变眼睑、眉间、嘴唇、下颌、呼吸、肌肉张力、姿态和重心；不得生成剧情环境、额外人物、卡通表情包或夸张图标。

完整分镜导演板可使用表演板为各 Panel 选择合适状态。默认 H3 不传整张表演板，也不为每个 Shot 制作表情裁图；先由完整导演板和自然中文 Shot 描述承载表演。只有真实视频 QA 反复证明某个近景表演无法从整板继承，且该问题确实值得占用图片槽时，才从 current 表演板提取并通过 QA 的一个单一干净状态参考。它必须限定当前 Clip/Shot，只控制微表情与身体反应语言，不含其他状态、文字、标签、边框、网格或拼贴，也不控制身份、具体姿态、动作阶段、视线方向、Camera Zone 或构图。

## QA

通过条件：所有状态仍是同一 Character + Look；状态差异可由眼睑、眉间、嘴唇、下颌、呼吸和身体反应读出；各状态符合该角色的表演语言并能组成当前 Clip 所需的非单调情绪曲线；没有依靠换脸、换妆、换光、换镜头或夸张表情制造差异。失败时只重做表演板，不改身份板。
