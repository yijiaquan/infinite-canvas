# Character Expression Board Method

用于主要角色需要重复近景、微表情承载剧情信息、关键情绪转折、审讯/悬疑/亲密表演，或已知身份参考会导致表情僵化时。它生成一张正式人物表情板：资产类型为 `expression`，父级必须是对应 Character 或具体 Character Look。完整表情板只进入导演板阶段；H3 只在关键近景使用它下属的一张干净单状态 `reference`。

## 职责与资产关系

- **Identity Board** 只回答“这个人是谁”：脸型、五官比例、年龄、肤色、发型、身体比例、固定 Look、服装与配饰。
- **Expression Board** 只回答“这个角色怎样表现这一组状态”：眼球焦点、眼睑、眉间/眉峰、嘴唇、下颌、面颊、呼吸、面部肌肉张力，以及与身体重心、肩颈、手臂和躯干的协同。
- 一个 `Character + Look` 对应自己的表情板。Look、年龄阶段、妆容或伤势发生实质变化时建立对应新板；旧 Clip 保留原有 version 绑定，不批量改写。
- 完整板使用 `kind: "expression"`，`parentId` 指向 Character 或 Character Look。可进入视频的单状态图片使用 `kind: "reference"`，`parentId` 指向来源表情板；两者都通过不可变版本和 `adoptedVersionId` 管理，不增加数据库列。
- 身份板中的中性站姿和表情不是 Shot 的表演指令；表情板不得改脸、年龄、发型、体型、服装或生成新 Look。

## 三层表演设计

1. **角色表演语言**：写在制作拆解中的长期文字习惯，记录情绪外露程度，以及察觉、怀疑、紧张、恐惧、愤怒、失控与恢复控制时常用的视线、呼吸、肩颈、手部和重心反应。它提供角色差异，但不能把角色锁死在一种反应里。
2. **Clip 表演曲线**：按当前剧情写 `开场状态 → 可见触发 → 上升/压制/爆发/回落 → 结尾残留状态`。强度只在同一角色、同一段落内比较，可以反复升降。
3. **Shot 可见表演**：把当前状态展开成触发、眼球焦点与聚焦距离、上下眼睑张力、眉间/眉峰、嘴唇/下颌/面颊、呼吸/颈部张力、重心与身体协同，以及结束变化。情绪名称或百分比不能单独成为模型提示词。

## 何时制作

以下情况满足任一项时制作：

- 主要角色有多次近景或跨 Shot 的渐进情绪弧；
- 微表情承担隐瞒、识破、犹豫、关系变化或其他关键剧情信息；
- 恐怖、悬疑、亲密、审讯等场次依赖克制微表情；
- 已知关键帧或视频容易出现同一中性脸、瞪眼张嘴、只换视线等表演失败；
- 不同 Shot 的角色身体反应语言需要保持同一人物习惯。

普通角色、远景角色或单次简单动作不制作表情板，直接在 Shot 语义中写可见表演。

## 完整表情板

一次请求生成一张完整表情板，背景简洁、无剧情场景、无道具叙事。根据角色和本集需要选择 5–8 个状态，不机械套用固定情绪清单。版面以大尺寸脸部/头肩微表情为主，让眼球、眼睑、眉间、嘴唇和下颌获得足够像素；同时保留肩颈、呼吸、姿态、手臂/躯干和重心提示，不能做成只有五官的表情包。

每个状态使用稳定 ID，并在制作拆解记录：目标 Panel/Shot、同一角色内部的相对强度、可见触发和结束变化。状态示例只用于理解结构：

- `E01 Neutral Alert`：正常警觉；
- `E02 Notice`：察觉异常；
- `E03 Suspicion`：怀疑与确认；
- `E04 Unease`：克制不安；
- `E05 Startled`：短促受惊；
- `E06 Suppressed Fear`：压制恐惧；
- `E07 Realization`：意识到事实；
- `E08 Frozen Terror`：极端恐惧后的冻结。

不同状态必须由眼球方向与聚焦距离、上下眼睑张力、眉间与眉峰、嘴唇/下颌/面颊、呼吸和颈部张力，以及肩膀、躯干、手臂和身体重心的对应反应读出。避免把所有恐惧画成瞪眼、张嘴和夸张后仰；优先体现压抑、否认、确认、克制、突然失控与恢复控制的差异。

## 强度与曲线

表情强度使用相对值 `0–100%` 表示同一角色内部的表演幅度，不是模型参数或跨角色评分。Shot 可以在内部写 `E06 / 60%`，但最终图片和 H3 提示词必须展开成可见肌肉、呼吸和身体行为。

情绪曲线不要求逐 Shot 单调上升。允许 `平静 → 上升 → 突发峰值 → 压回去 → 再次上升 → 最终峰值`，只要每次变化由可见触发和人物选择支撑。

## 阶段绑定与 H3 使用

- 导演板阶段使用 `role: "expression"` 绑定完整 `expression` 表情板。导演板按目标状态吸收微表情、呼吸与身体响应，但不得复制宫格、标签、文字、白底或其他状态。
- 视频阶段的 `role: "expression"` 只接受父级为该表情板的单状态图片 `reference`。完整宫格表情板禁止直接进入 H3，避免其他状态、边框和文字污染成片。
- 关键近景、特写或大特写若已在制作拆解中标记，可在首次 H3 生成前主动使用一个干净单状态参考，无需等待视频失败；真实 QA 的定向返修也可使用。
- 单状态参考必须限定当前 Clip/Shot，只控制微表情与身体反应语言，不控制身份、Look、具体姿态、动作阶段、视线目标、Camera Zone、构图或其他 Shot。
- H3 图片顺序固定为完整导演板、实际出镜身份板、单状态表情参考、当前完整场景板、关键道具与其他必要参考。九图不足时优先保留导演板、身份板和场景板；表情参考只有承载关键剧情信息时才优先于次要道具或一般参考。

## Prompt 与 QA

静态请求必须声明：current 身份板控制不可变身份与 Look；本表情板只创建同一角色的表演语言；每个状态使用同一脸、发型、身体比例和服装；状态之间只改变眼球/眼睑、眉间、嘴唇、下颌、呼吸、肌肉张力、姿态和重心；不得生成剧情环境、额外人物、卡通表情包或夸张图标。

完整表情板通过条件：

- 5–8 个状态仍是同一 `Character + Look`，脸部像素足以检查细微变化；
- 状态差异来自眼睑、眉间、嘴唇、下颌、呼吸和身体张力，不靠换脸、换妆、换服装、换光或换镜头；
- 每个状态能对应其稳定 ID、目标 Panel/Shot、触发、相对强度和结束变化；
- 各状态符合该角色的表演语言，并能组成当前 Clip 所需的非单调情绪曲线。

单状态子参考还必须只有同一角色的一个状态，没有其他状态、文字、标签、边框、网格、拼贴或白底板式。H3 成片必须复核没有宫格、标签、白底或其他表情泄漏，且面部变化与肩颈、呼吸、姿态和重心反应同步。失败时只重做表情板/单状态参考或受影响 Shot，不改身份板。
