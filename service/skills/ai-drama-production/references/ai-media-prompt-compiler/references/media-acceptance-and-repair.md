# 真实媒体验收与最小返修

这是一张供制作代理内部使用的轻量验收卡。它只依据真实图片、真实视频及其实际播放结果判断，不创建评分、Verdict、Finding、JSONL、审批表或项目级 QA 报告。

请求成功、Prompt ID、History 完成、文件存在、命令退出成功，甚至“可以播放”，都不是验收通过。只有媒体实际兑现当前导演目标、连续性与技术可用性，才可采用为 `current`。

## 三种结果

- `adopt`：所有本次适用的关键项通过。复制现有文件到 `资产/` 或 `媒体/` 并沿用既有索引登记为 `current`；不继续为同一目标追加候选。
- `targeted_repair`：存在一个可观察、可定位的缺陷。使用原媒体、current 身份/Location + View/道具或 Voice，写清唯一问题、目标变化与 preserve 项；一次只改变一个主要变量。
- `blocked`：分镜导演板/资产无法表达已确认 Beat、真实基础设施不可用、权利问题或不可调和的创意冲突。普通审美取舍、排队、记录和技术细节不是阻塞。

除非结果明显未兑现已声明的动作、反应、摄影或情绪转折，否则“更喜欢另一种风格”只作为后续创作偏好，不触发无限重抽。`performance_flat` 是功能性缺陷：动作虽勉强出现，但身体、反应、注意力、摄影或状态变化仍明显静止，应返修。

## 补拍与整镜替换

H3 不做时间段局部编辑。分镜 Clip 中一个 Shot 有明确缺陷时，先判断是否存在自然切点可生成独立替换 Shot 交给必剪；否则重拍完整 Clip，并保持原分镜 Beat、顺序和结尾状态。

只有新版本真实兑现原 Clip/Shot 的全部已批准职责，才替换原媒体。若需要的 Beat 无人认领，退回分镜导演板或按真实编辑理由调整 Panel/Shot；不新增补拍台账、版本裁决或审批步骤。

## 图片验收

先看真实像素，再做当前类型适用的检查。任一关键项失败即 `targeted_repair`；未生成或无法读取才按真实原因处理。

### 通用项

- 实际输入的参考职责未被越权：身份、地理、道具、风格和 source board 各自只控制声明层。
- 主体、数量、当前状态、构图焦点和必要细节可读，且没有明显生成瑕疵、无关主体、水印、错误可读文字或任务已知失败项。
- 图片真的服务当前用途，而不是一张好看但无法给下游复用的氛围图。

### 身份板

- 一次生成的一张完整艺术多视图板，而不是散图联系表或事后拼图。
- 只对应一个 `Character + Look`；脸、发型、身体比例、服装、鞋靴和固定配件在全部视图一致。
- 整板明确分成约 35%–40% 的身体结构区和约 60%–65% 的大尺寸头部身份区；两区能自然重组为同一个完整角色。
- 身体结构区只从颈根/肩线以下展示正/侧/背/3-4 身体视角，手、脚、四肢、体型、服装和固定配件完整可用；颈根裁切中性、干净，不出现伤口、血液、断面或暴力含义。
- 头部身份区明显更大，默认只有 3 个大头部/头肩视图：最大的正面主视图、一个 3/4 视图和一个侧面视图；不重复左右对称角度，不默认加入后脑或额外五官小图。脸、下巴、耳朵、发际线和发型外轮廓不被裁掉，基础表情中性且三个视角五官一致。
- 两区的肤色、年龄、颈宽、体型和 Look 一致；不得把身体区生成成假人、不同身体或第二个身份。
- 分隔清楚、留白足够、不重叠、不合并角色，背景不偷带剧情场景。
- 身份板只证明身份与 Look；其姿态、视线和表情不得被当作后续 Shot 必须复制的表演。

### H3 干净单图参考

- 身份参考只出现一个角色，脸、发型、体型与 current Look 清晰可辨；面部身份参考优先是头部区派生的大尺寸单视角头肩图。需要全身时必须是头脸与身体正确重组、从头到脚完整可见的单人图，绝不使用身份板中的无头身体研究。表演参考只出现同一角色的一个状态；道具参考只出现一个干净单体；场景参考是正常 `Location + View` 静帧。
- 不得出现完整身份板、表演板、道具板、Look Board、其他视图/状态、文字、标签、边框、网格、拼贴或白底板式。Look 由完整分镜导演板承载，不另传色卡板。
- 裁切不得丢失当前 Clip 真正需要的身份、表演或道具信息；简单裁切不成立时，用完整上游板作为静态生图输入重新生成单张干净参考，再按真实图片 QA。
- H3 Prompt 必须把来源图片抽象成对应 `<Subject N>`；来源 Picture 不得在动作正文中被当作需要展示的画面反复调用。

### 人物表演板（按需）

- 仍是同一 Character + Look，且没有通过换脸、换妆、换服装、换光或换镜头制造状态差异。
- 不同状态可由眼球、眼睑、眉间、嘴唇、下颌、呼吸、面部张力和身体重心/肩颈/躯干反应读出。
- 克制恐惧、怀疑、确认、受惊、压制和冻结等状态不全部退化为瞪眼张嘴；强度是同一角色内部相对范围，不改变身份。
- 完整表演板只服务分镜导演板；H3 如需表演参考，另验收一个单一干净状态裁图，不能直接传表演板。

### 完整场景板、场景主图与 View

- `hero_recurring` 或确需多方向覆盖的 `standard` 地点，完整场景板是一张 16:9、2×3 六区板：主视角、反向、左右斜角、入口/连接方向和俯视拓扑；不是六张独立生成后拼接的风格图。
- 六区必须能够闭合为同一个空场：墙体、门窗、出入口、路径、固定物数量/位置、Anchor、尺度、材质、时间状态和主光互相一致；俯视拓扑不能与透视视图冲突。
- 场景板是上游空间身份资产，不能冒充正式导演板；对重复、多方向或复杂 Location，它同时作为 H3 的常规地理 Picture。验收时必须确认提示词不会把六区网格、标签、其他角度或拓扑小图带进成片。派生的 `scene_master` / `scene_view` 必须是无边框、无标签、无其他角度、无拓扑小图的干净单视角图，只服务静态导演板构建。

- 场景主图默认空场；入口、出口、路径、地标、固定物、主光、材质、尺度和可见边界与当前 Location 一致。
- 新 View 只改变机位与朝向，新露出的部分自然接合既有空间；不镜像、移动门窗、重排地标或新造房间。
- 只有已声明必要时才有无身份尺度参照；不得加入人物剧情或额外道具填画面。

### 道具板

- 道具的轮廓、比例、尺度、材质、功能结构和永久识别痕迹可辨。
- 当前开合、损坏、内容物、数量、文字策略和持有/安装状态自洽；不把临时手位或单镜动作误做成新道具身份。
- 绳索、手铐、背带、软管、线缆、牵引物或插入式连接件跨镜影响行动、剧情或安全时，归属者、端点 A/端点 B、可见路径/机制和当前模式可辨；单独道具板不能假装证明它在场景里仍连接。
- 人物或环境没有压过道具主体，也没有产生额外复制品。

### 完整分镜导演板

- 每个 Clip 的完整全彩导演板按实际 N 镜验收：主镜头数、编号、时间、动作及交接对应当前镜头表；页眉与底部参考/简表清楚可读，主画面足够大。完整导演字段在工作台镜头表中核对，不要求每格印满 CAMERA/BODY 等卡片。参考缩略图不计为 Shot，不得因版式不足丢掉镜头。
- 继承当前 Project / Scene Look、Color State 和 Lighting State；肤色、阴影/高光、黑位、对比/饱和度、材质响应与强调色职责正确。局部色光变化来自已声明 Light ID 或可见新光源，不是无来源全局滤镜。
- 关键剧本 Beat 在对应 Panel、Shot 内连续动作或明确画外载体中真正有可见承担；不让 H3 在没有依据时补造事件。
- 双人、门口、交接、揭示、追逐或群像中，声明为主状态变化的动作只在指定 `primary_action` Shot 完成；其他 Shot 只建立、反应、插入或交接结果，不得重复或提前完成同一事件。
- 身份/Look、人数、相对尺度、Location + View、地标、道具数量/归属、轴线、摄影机工作侧、画面左右和主光在相邻帧之间连续。
- 适用的连接道具在相关 Panel 中保持归属者、两端、路径/余量和模式；若一端暂时出画，已写明出画端及邻接验证镜。无故消失、松脱、换端或从固定连接静默变成自由移动均不通过。
- 同场直接切镜确实有已声明的景别/取景重点、观察侧/POV、人物或道具关系变化之一；相邻 Panel 能在相对锚点位置、行动阶段和道具归属上接住上一末态，不把“正在接近”直接画成“已操作”。
- 人物动作优先是可继续的 `mid_state`；身体姿态、重心、头肩手腿躯干、视线和表情共同服务 Dramatic Beat，不是身份板中性站姿加换眼神。
- `Location + View` 保持地理但不锁死 Camera Zone。相邻 Shot 除非有明确固定覆盖理由，Camera / Body / Information 通常至少两项可读变化；连续复刻同一景别、机高、方向、人物位置和前中后景不通过。
- 目标 Panel 返修后复核其余格及前后状态交接；通过的完整整板才可采用为 `director_board`。
- 低饱和/黑白预演板只按主人明确要求作为独立预演资产验收；它不能覆盖或冒充本 Clip 的全彩正式 `director_board`，也不作为默认 H3 `<Picture 1>`。

## 视频验收

对话、观察和对峙额外检查眼线：角色双眼必须落在已声明的场内人物、道具或空间点，目标位置、距离和眼线高度与画面一致。除明确 POV、自拍、视频通话、演讲或直面观众外，无剧情理由直视镜头、双方视线不交汇、看错画面侧或无触发换目标，均属于 `eyeline_failure`。

在正常速度、目标画幅下观看真实视频；只有快速动作、对白、接缝或可见瑕疵高风险时，再按需检查一秒采样或逐帧。一个分镜 H3 Clip 的关键项如下。

1. **剧情与导演板**：分镜导演板承诺的 Shot 顺序、可见动作、反应、画面方向和结尾状态真正发生，未提前泄露后段信息，也没有身份板、表演板、道具板、Look Board、角色参考卡、白模、线稿、格线、箭头、编号、标签或任何来源图片版式污染成片。需要控制的信息必须按声明的载体与触发出现；若它改变选择、关系、权力或威胁，当前或下一 Shot 必须出现可读的接收后果，而不能只靠角色“内心明白了”。
2. **表演与摄影**：存在 `触发 → 身体准备 → 行动 → 回应/阻断 → 反应/选择 → 改变后的状态`。人物不能只站着念台词；身体重心、躯干、肩颈、手臂/腿、视线、呼吸与面部肌肉应共同承担表演，身份参考不得冻结姿态和表情。主要摄影行为服务动作、注意力、揭示或空间压力，不能遮住事件或无故跳变。同场相邻 Shot 除非明确固定覆盖，Camera / Body / Information 通常至少两项发生可读变化；连续同景别、同机高、同方向、同主体位置和同层次属于 `camera_failure`。高风险 Shot 的动作只在其声明职责中发生，不重播同一开门、交接、进入或揭示，也不让反应 Shot 偷偷完成后续动作。
3. **视觉连续性**：身份、Character Look、人数、相对尺度、Location + View、地标、道具数量/归属、手持关系、适用连接道具的归属者/两端/路径/模式、屏幕方向和主光正确；Project / Scene Look、Color / Lighting State、肤色、阴影/高光、黑位、综合色温、材质响应和强调色来源没有无动机漂移。
4. **声音**：精确台词、Voice、语言/发音、表演、口型与 A/V 同步正确；环境、Foley、SFX 与可见动作一致。原生音轨存在不等于通过。
5. **接缝**：同场连续的两张正式故事板先并排检查上一板末格与下一板 P1；状态未继承时不得提交下一 Clip。连续 H3 Shot 在采用当前 Shot 前，再预览上一 Shot 末尾与当前 Shot 开头约 2–3 秒，检查人物区域/姿态/重心、持物、目光、固定陈设、方向、光线、房间底声、对白尾音与动作声；直接切镜有可读覆盖变化，路径动作能在相对锚点位置、行动阶段和道具归属上从上一末态抵达下一开场。连接道具还核对归属者、端点 A/端点 B、路径/余量和模式。无解释的到达、下跪、交接、开门、固定陈设重排、连接消失/松脱或道具状态跳跃不通过。
6. **技术可用性**：时长、画幅、分辨率、FPS、帧数、音轨和可播放性符合目标，且目标裁切下没有破坏叙事的可见故障。

补拍或新增插入前还要看它与相邻 H3 Shot 的剪辑衔接：它确实补上唯一缺陷或认领的 Beat，同时没有删掉原 Shot 仍要承担的动作、反应、对白、信息或终态。

摄影稳定性按正常速度观看判断：固定镜头保持构图，移动镜头按既定路径平滑运动并在落点停稳。非设计的全幅高频晃动、水平线摆动、追踪抽动或落点持续游移属于 `camera_failure`；不因“有电影感”放行。明确设计的短促手持/冲击按其范围验收，不要求这些例外完全静止。若只有人物轮廓、墙面或道具局部扭曲而非全幅刚性运动，先检查生成形变/时序稳定性，不能统称手持或靠改镜头词宣称解决。必要时对源视频抽帧定位，但不能以单张静帧替代连续观看。

返修优先保留原剧情、对白、镜头数、时长与参考，只修摄影稳定性描述或错误的运动参考；画面内容正确且轻度全幅抖动能通过后期稳定处理时，可在核对裁切、边缘形变和主体保留后走 `post_fix`，否则按既有规则重拍受影响 Shot/Clip。不能靠强裁切或把动态镜头变成静态画面掩盖问题。

## 可观察缺陷与最小返修

先命名真实症状，再选择既有返修路线；不要把每次失败都改成整场重做或换模型。

| 失败类别 | 可观察缺陷 | 首选处理 |
| --- | --- | --- |
| `asset_reference_drift` | 脸、Look、人数、道具形制或参考职责漂移。 | `targeted_edit`（已验证图片编辑时）或修正 `reference_authority` 后生成/受影响 H3 Shot 重拍。 |
| `space_prop_continuity` | 地理、入口、地标、持物、轴线、主光或连接道具的归属者/两端/路径/模式不连续，或人物/道具无可见路径就跳到无法物理抵达的位置或状态。 | 修场景/道具/目标 Panel 绑定，补认领过程的 `transition` Shot，或把前一 Shot 落到可剪的完成状态；连接道具同时修真实道具参考、整板中的实际连接关系和 H3 输入；新角度先建立实际 View。 |
| `performance_flat` | 动作没有落地、只有结果姿势、身份参考冻结表情/姿态、身体重心与肢体不动、反应或结尾状态缺失。 | 修 `performance_arc`、动作中间态或表演参考职责；H3 只 `shot_retake`。 |
| `eyeline_failure` | 人物无剧情理由直视镜头、双方视线没有交汇、看向错误画面侧，或视线转移缺少目标与触发。 | 修当前 Panel/Shot 的 `Eyeline Contract`、头部角度、眼球落点、越肩/POV 关系与目标位置；整板正确但 H3 漂移时重拍受影响 Shot/Clip。 |
| `camera_failure` | 摄影机无动机、跳变、遮住事件，或相邻 Shot 复刻同一景别/高度/方向/人物位置/层次，没有足够 Camera / Body / Information 变化。 | 修 Camera Zone、`camera_contract` 或 Shot 设计；合并同一连续 Shot，或按真实编辑理由建立新的覆盖。 |
| `look_color_drift` | 肤色、阴影/高光、黑位、综合色温、对比/饱和度或强调色职责漂移；光源变化没有 Light ID、画内事件或可见来源。 | 若内容与光源动机正确，仅匹配偏差则 `post_fix`；若导演板/Color/Lighting State 已错，先修目标 Panel，再按自然切点替换 Shot 或重拍完整 Clip。 |
| `sound_failure` | 台词、Voice、口型、同步、环境或动作声错误。 | 修 `Line/sound route`、Voice/音频绑定或走明确的后期口型修复；保留或重建环境/Foley/SFX。 |
| `technical_or_post_failure` | 仅裁切、字幕、调色、混音、导出参数问题。 | `post_fix`，不重做生成内容。 |
| `board_or_prompt_failure` | 分镜导演板/提示词无法表达批准 Beat，或基础设施/权利真实不可用。 | `rewrite_prompt_or_board` 或 `blocked`；不要用幻灯片、拼贴、板面动画或静态推拉交差。 |

H3 未验证时间段局部编辑。任何需要重生成的缺陷只在自然切点成立时做独立替换 Shot，否则重拍完整分镜 Clip；不声称“直接修视频第几秒”。

## 使用边界

这张验收卡不替代制作判断，也不要求把每次内部检查写入项目。Visual Skill 负责静态图与完整分镜导演板的实际观看，Video Skill 负责 H3 成片与接缝，Short Skill 负责必剪整片观看。它们都只在真实质量问题时返修，并将成功结果采用为现有 `current`。
