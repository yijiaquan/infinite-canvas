# H3 Clip Semantic Template

用于一个本地 H3 Clip。先有剧本、动作、`Character + Look`、`Location + View`、道具、完整导演板与声音语义，再按此写内部 Master H3 Clip Contract；Prompt Skill 根据模式写为官方 Ref2VA 六段或 FL2VA/Base 三段最终格式。

本页是内部导演合同，不是直接提交给模型的最终提示词。Project/Episode/Clip/Panel ID、Scene Bible、Top-Down、Camera Coverage 和优先级只用于内部取值；最终只输出当前 Clip 必需的可见、可听事实。不适用字段直接省略，不写 `N/A`，也不把 `Lock`、管理编号或整份表格复制进 H3。

## 基本规则

- 一个 H3 Clip = 一次同场、同时间、状态连续的请求。实际 N 镜与时长 T 根据剧情、动作和对白决定，执行使用当前已验证的 2–15 秒范围；分镜时长可以不均等，但共同形成清楚因果。
- Ref2VA 的 `<Picture 1>` 固定为当前 Clip 的完整导演板。它控制实际各 Shot 的顺序、覆盖、构图、调度、动作阶段、空间锚点与 Look 关系；不拆成多张 Picture。
- H3 直接接收实际出镜人物的完整身份板、关键近景所需单状态表情参考、当前完整场景板和实际关键道具板；不派生或追加常规单视角人物、场景或道具图。完整 `expression` 人物表情板与 Look Board 只服务上游整板生成，禁止直接进入 H3。制作拆解已标记的关键近景、特写或大特写可在首次生成前追加一张父级为表情板、限定当前 Clip/Shot 的干净单状态 `reference`；真实视频 QA 返修同样适用。所有板式参考都必须声明控制域，并明确其白底、网格、分区、标签、文字和多视图布局不得进入成片；关系锚点或实际 Speaker Voice 仅按风险与声源需要加入。
- `subject_definitions` 将人物、场景、道具与表演图片定义为 `<Subject N>`。相邻 Clips 先完成整板 末格/下一板首格 交接和定向返修；只有真实 QA 仍证明某个构图、站位或跨 Clip 开场状态不稳时，才增加一张后续彩色关系锚点并限定适用 Shot/连续关系；它不替代整板的 Shot 顺序。具体方法见 [跨 Clip 故事板交接与关系锚点](clip-boundary-blocking-anchor.md)。
- 选用白模预演时，优先把该 Clip 的同场连续预演接入一个 `<Video N>` / `video_N_frames`，只控制摄影机路径、工作侧、调度和动作节拍；若确需多个覆盖视频，必须逐一限定适用 Shot。
- 默认让同一人物、同一目标和同一连续因果在一个 Shot 内完成。新机位、反打、反应、插入、独立动作阶段、空间关系或信息变化只有在带来新必要事实、读清关键动作、改变观察立场或形成不可替代节奏重音时才成立；简单微动作、普通反应和可并行对白表演并入当前 Shot。复杂状态交接、跨场或参考冲突才新建 H3 请求。
- 同场直接切到新 Shot 时，至少改变景别/取景重点、观察侧/POV、人物或道具关系之一；如果没有新观看任务，合并为同一连续 Shot，或重设覆盖。`Location + View` 稳定空间拓扑与轴线，不要求镜头保持同一构图。
- 同一 `Location + View` 内的 `Camera Zone` 是合法摄影区域，不是固定坐标。先证明切镜价值；切点成立后，相邻 Shot 除非明确采用有目的的固定覆盖，通常让 Camera / Body / Information 三项至少两项产生可读变化。不得为了满足该变化指标反向制造 Shot。
- Ref2VA 默认按整板完成同一连续事件中的多次建立/反打/反应/插入/揭示覆盖；每个后续 Shot 必须增加新信息或表演，不把无关蒙太奇交给同一 Clip。FL2VA 只描述两张端点之间的一个连续过程。
- 关键 Beat 必须被一个 Shot 或明确画外载体认领；同一主状态变化只由一个 `primary_action` Shot 完成。
- 打斗 Clip 先按 [高密度打斗、技能与能力调度](combat-and-ability-staging.md) 写完整 Clip 的攻防脊柱，再把每一轮可读战术变化映射给一个 Panel。P1–末格 共同完成即时威胁、首次应对、余势位移、换轴/命中、技术交换、优势逆转、追击封锁和结果/进行中切出；实际剧情可调整阶段，但不能退化成多条孤立招式或在切镜后复位。
- 一次连续发言必须指定唯一 `dialogue_owner_shot`。完整可朗读原文只在该 Speaker 的一个 `<d>` 中保存一次；其他 Shot 只描述同一次发言的准备/中段/收束/说完后阶段与表演，不能复述原句、短句、关键词或引号。声音段只写时间、声源、空间、尾音和声桥。
- 内部导演合同可用 `镜头功能`、`CAMERA`、`BODY/ACTION`、`INFORMATION`、`CONTINUITY`、`SOUND`、`END STATE` 保证分镜规划完整。最终 Ref2VA 保留官方 `detailed_description`、Shot 标签和时间戳语法，写成中文逐镜自然叙述；Shot 3–8 与前两镜同样具体，不用省略号、`same as above`、`同上`或一句承接说明。
- `开场状态`、表演曲线和身体维度都是内部取值，不得逐字复制到最终 Prompt。最终 Shot 首句直接写人物在具名锚点或明确画面区域的动作；同一人物未发生可见移动、摄影机重构或有动机换轴时，继承上一镜位置，不从“左侧”无过程跳到“画面边缘”。

## Shot Map

在制作拆解同一张 Shot 表中填写：

| Clip / Panel / Shot | Time | 认领 Beat | Shot 功能 / 唯一主状态变化 | 必须出现的动作与可见结果 | 相对上一镜的覆盖变化 / 切点理由 | 摄影 / 声音落点 | 下一 Shot 必须继承的状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |

整板 Panel 建立该 Shot 的可读瞬间。过程中的 trigger、身体准备、动作、回应、反应/选择和结束状态必须由对应 Shot 的动作正文完成，并与下一格交接。

填写 Shot Map 前先压缩：合并同目标连续微动作、同步对白与身体任务、可在主镜内读到的听者反应和摄影跟随；删除重复建立、重复反应、无功能插入与无功能余韵。逐镜执行删除测试，删除后不损失剧情事实、关键动作可读性、观察立场或节奏重音的候选 Shot 不得进入最终 Shot Map。

同场有两个以上 Shot，或有路径/关键交互时，在同一制作拆解再写一行轻量覆盖关系：`观众必须读到 → 相对上一镜的覆盖变化 → 切点理由 → 当前末态到下一镜开场`。涉及移动或姿态转换时，写成 `上一末态 → 本 Shot 起点 → 可见路径/完成动作 → 本 Shot 末态 → 下一起点`；没有可读过程就不能把“接近目标”直接切成“已到达并操作”。跨镜连接道具再写 `归属者 → 端点 A → 连接路径/余量或滑动方式 → 端点 B → 当前模式`，不得在切点把“仍相连”静默变成“已脱离”。

## 标准语义 Brief

```text
任务与目的：[H3 Clip ID] 在 [实际 T 秒] 内，让观众依次看见 [实际 N 个] Shot 把 [认领 Beat 范围] 从 [start_state] 发展为 [end_state / 可见证明]。

模式：[Ref2VA / FL2VA endpoint test / other Base mode]。
输入职责：Ref2VA 的 <Picture 1> 是本 Clip 的完整导演板，控制 [Shot 顺序、各格构图、观众画面位置、朝向/视线、动作阶段、摄影机工作侧、固定锚点与 Look]；后续 <Picture N> 依次是 [实际出镜人物完整身份板 / 当前完整场景板 / 实际关键道具板 / 按需关系锚点]，分别只控制其声明的身份、地理、形制、State 或关系；FL2VA 则分别声明 Picture 1 开场端点与 Picture 2 落点端点。
[定义 Subject：<Subject N> 的身份来自完整身份板 <Picture N>；当前 Location 的地理来自完整场景板 <Picture N>；关键道具的形制/状态来自完整道具板 <Picture N>。每项写控制域与禁止越权域，并明确板内白底、分区、文字、网格、拓扑图和多视图排版不是成片内容。跨镜连接道具对应的 <Subject N> 控制归属者、两端、连接路径/机制与当前模式；不能改写身份或地理。]
[选用 Blender 白模时必须填写：<Video 1> 是同 Clip 已通过且实际接入 `video_1_frames` 的 Blender `*_reference.mp4`，只控制实际各 Shot 的 [摄影机路径、工作侧、屏幕左右、空间调度、动作节拍、递增切点与落点]；不继承白模代理形体、材质、颜色、标签、UI 或源音频，也不替代 <Picture 1>。]
[有台词时：<Audio N> 只为实际 Speaker 提供音色参考；不复制样本台词或背景。]

开场状态：[人物、道具、空间、光线、AMB；若适用，连接道具的归属者、端点 A/端点 B、路径/余量和模式]。
[内部角色表演语言与 Clip 曲线：该角色惯常的外露/压制方式；开场状态 → 可见触发 → 上升/压制/爆发/回落 → 结尾残留状态。只供编译取值，不作为最终句式。]
[内部动态导演：Camera Zone；景别/焦段/机高/角度；Foreground / Subject / Background；身体姿态、重心、视线、Action Phase 和必要表演变化。完整维度只用于检查，最终正文选取会改变画面的一两个反应，不罗列身体部位。]
[对话/观察/对峙/POV 时：Eyeline Contract=角色当前注视的具名人物/道具/空间点；目标的场内位置、距离和眼线高度；摄影机观察位置与脸部角度；视线转移的可见触发及新目标。普通客观镜头让双眼落在场内目标，只有明确 POV、自拍、视频通话、演讲或直面观众才把镜头方向设为注视目标。]
[三人以上时：焦点人物/具名配角各自的命名锚点、观众画面区域和朝向；每个 `Crowd-*` 簇的人数、区域、整体朝向、密度和可走通道；未声明的对象不得重排。]
连续动作：[trigger → 身体准备 → committed action → 对方或环境回应 → reaction/choice → changed end state；连接道具若仍生效，始终保持同一两端与模式，若改变则把变化作为本 Shot 可见动作]。
[有路径或姿态转换时：上一末态 → 当前起点 → 可见路径/完成动作 → 当前末态 → 下一起点；人物相对锚点、朝向、行动阶段和道具归属均可读。连接道具还须可读其两端、路径与模式；允许某端出画时，写明哪一端与相邻验证镜。]
摄影：[一个主镜头行为；稳定支撑与起始关系 → 触发 → 平滑路径/速度 → 减速或停稳落点；明确选用手持/冲击时才补具体时段、幅度及恢复稳定的状态]。
声音：声源=[画内对白 / 画外对白 / 旁白 / 无台词]；Dialogue=[实际 Speaker；dialogue_owner_shot；唯一精确 Line；语言；时间窗口；其他 Shot 的连续发言阶段]；AMB=[延续/进入/退出；一个可听空间锚点]；Foley/SFX=[可见或明确画外事件，只写声音事件]；Music=[none / 延续 / 进入 / 退出 / 为对白让路，或画内声源]。
必须保持：[身份、Look、人数、Location + View、固定锚点、道具归属、跨镜连接道具的归属者/两端/路径/模式、屏幕方向、主光、已发生状态]。
允许变化：[仅本 Shot 已声明的动作、状态、摄影或声场变化]。
结尾与交接：[可验证终态、声音尾部、下一 Shot 必须继承事项]。
```

## 复杂 Shot 按需增加

多人、对白、递交、门口、追逐、悬疑发现或群像才添加：

- **空间合同**：观众画面左右、轴线、摄影机工作侧、人物/道具/入口的位置、3–5 个可见固定锚点和允许越轴方式；三人以上时还包含每个焦点人物/具名配角的锚点区域，以及 `Crowd-*` 簇的人数、区域、整体朝向、密度、通道与唯一允许重排；
- **Shot 职责**：`establish / primary_action / reaction / insert / transition`，只写本 Shot 应完成的任务；
- **信息控制**：`现在给出 / 暂时隐藏 / 揭示触发 / 接收后的可见后果`；
- **对白承载**：说话前任务、说话时身体行动、听者/环境响应、台词后的变化；精确台词装不下时拆 Shot，不压缩或改写。
- **表情参考**：完整 `expression` 表情板只服务上游导演板设计；微表情、呼吸、重心与身体表演必须已经写进完整导演板对应 Panel 和最终 Shot 描述，同时由完整身份板保持角色身份。制作拆解已标记的关键近景可在首次生成前加入一张干净单状态子参考，真实 QA 返修也可使用；它必须限定 Clip/Shot，只控制微表情和身体反应语言。

打斗、武器、法术、异能、怪物能力或范围技能攻击时，额外读取 [高密度打斗、技能与能力调度](combat-and-ability-staging.md)。先完成 Clip 级的连续因果路线和优势转换，再在同一 Shot 表中为每个 Panel 补足行动主导者、双方距离/朝向/重心、关键物或效果源头、目标方向/范围、唯一主行动、受控响应、可见后果及可继承终态。一个 Panel 不承担整套连招或多轮攻防；上一 Panel 的余势、位置、装备和环境后果必须成为下一 Panel 的真实起点。

## 提交前静默检查

- 对话、观察和对峙的注视目标、目标位置/距离/眼线高度、摄影机观察位置与转移触发具体可见；普通客观镜头不存在无剧情理由的镜头直视，明确 POV 则保持摄影机所代表角色与眼线关系一致；

- 每个 Beat 已被 Shot 或画外载体认领，且没有重复完成同一主动作；
- Ref2VA 的 `<Picture 1>` 是通过 QA 的完整分镜导演板；后续图片是实际需要的完整身份板、完整场景板、关键道具板或明确的高风险关系锚点，不是实际各 Panel 裁图或常规单视角派生图；FL2VA 两张端点均已通过 QA；
- 每个 H3 Picture 槽只连接一个职责明确的真实图片文件；它可以是完整导演板、完整身份板、完整场景板、完整道具板或按需关系锚点，但不能是临时拼贴、重复图、散乱 Panel 裁图或常规单视角派生图。最终语义以 `<Subject N>` 正向描述成片中的真实角色、场景、道具、表演与连续真人电影构图，板式清洁检查留在提交前 lint，不复制进 H3 提示词；
- 选用 Blender 白模预演时，唯一 `<Video 1>` 的输入、编号、分镜 Shot 范围和职责必须与语义 brief 一致；视频包含同 Clip 的连续覆盖和切点，且对应 `video_1_audio` 未因白模而连接；
- 一条 Shot 只有一个受动作或注意力驱动的主要摄影行为；
- 身份参考没有把中性表情/站姿越权带入 Shot；动作 Panel 优先是可继续的 mid-state；每个切点先通过新事实/关键动作可读性/观察立场/节奏重音检查，再确认相邻 Shot 的 Camera / Body / Information 至少两项变化或具有固定覆盖理由；
- 同场相邻 Shot 的直接切点有新的可读覆盖，且当前开场能从上一末态在位置、行动阶段、朝向、道具归属及适用的连接道具两端/路径/模式上合理到达；多人场面同时保持未获准改变的具名人物与 `Crowd-*` 簇的区域、朝向、密度和通道；
- `无台词` 不接 Voice；每条 Audio / Speaker / dialogue 都有一个精确 Line；每次连续发言只在唯一 owner Shot 的一个 `<d>` 中出现，其他 Shot 和声音段没有可朗读文本或显著子串复述；
- 内部 Shot Map 完整填写镜头功能、摄影、身体动作、信息、连续性、声音与结束状态；导演板以大幅画面、编号/时间和底部简表表达，完整字段不重复印入每格。最终 H3 Prompt 逐镜改写为自然中文叙述，保留官方标签和时间戳；
- AMB 交接、Foley/SFX 与可见事件一致，非画内 BGM 保留为必剪时间线意图；
- 最终成片语义明确为完整彩色真人电影画面，只呈现故事世界；不把整板纸张、网格、箭头、编号、标签或说明文字当作画面内容，也不伪造时间段局部编辑。

最终提交前按模式读取 [H3 Ref2VA 统一最终提示词模板](../../minimax-h3-video-production/references/h3-ref2va-final-prompt-template.md) 或 [H3 FL2VA 端点测试模板](../../minimax-h3-video-production/references/h3-fl2va-test-template.md)，并执行 [H3 提示词编译与校验](../../minimax-h3-video-production/references/h3-prompt-compilation-and-validation.md)。
