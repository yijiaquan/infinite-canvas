# 镜头语言与运镜选择

本页用于分镜导演板和 H3 Shot 的摄影选择。它帮助把剧本 Beat 转成可拍的注意力路径；不增加确认、镜头配额或单独文档。先决定观众此刻为何要改变注意力，再选固定机位或一个主运镜。不要为了“电影感”平均堆叠技巧。

## 先分开三件事

- **观察角度**：正面、斜侧、正侧、后斜侧、背面，决定观众站在谁的一侧、能读到多少表情。
- **机位高度**：低、平视、高、顶视，决定力量、距离和空间压力；平视也是主动选择。
- **焦段意图**：广（空间关系）、标准（自然观察）、长（压缩纵深、隔离主体）。

它们是构图/调度，不等同于运镜。切到新角度、反应镜或门外不是运镜，而是同一分镜导演板中一个有真实编辑理由的新 Shot；只有越出当前 Clip 的场景、时间、状态或容量边界才建立新 H3 请求。

## 选择顺序

默认采用稳定摄影。先分清三种变化：人物/道具的运动、镜头之间的覆盖切换、镜头内部的摄影机运动。前两项不要求摄影机抖动；稳定摄影仍可推拉、横移、跟拍、环绕或摇摄，并不等于每镜固定不动。

- 固定机位：以三脚架式稳定支撑保持构图和地平线，变化由画内表演承担。
- 移动机位：默认采用轨道、稳定器或稳定云台式受控运动；写清平滑路径、速度、水平或有意俯仰关系，以及减速和停稳的落点。这里是生成目标描述，不要求另建摄影器材资产。
- 手持是明确的摄影风格例外，不由“紧张、真实、电影感、呼吸、奔跑、POV”自动触发。只有项目明确选择该风格，或该 Shot 确需主观失衡时，才写受控手持的幅度、开始/结束阶段及恢复方式；不能由一个局部例外扩散为整段默认。
- 冲击首先改变人物、物件或环境；桌子震动、脚步、拳套接触、衣服惯性不等于镜头受震。摄影机需要受震时单独说明触发、短暂范围和随后稳定观察的状态。
- 上游白模/参考视频含有抖动时先核对是否符合上述摄影意图；不能仅因它是相机参考就默认继承噪声。用户明确指定的手持原意应保留，不在格式转换时静默改掉。

这些内容进入既有镜头表的摄影栏和 H3 Shot 自然中文正文，不新增必填 JSON 字段、负向提示词或确认步骤。

每个 Shot（及其对应 Panel）依次写清：

```text
镜头目的 → 起始构图与稳定支撑 → 触发点 → 固定或主运镜 → 平滑路径与速度
→ 注意对象 → 减速/停稳落点 → 必须保持的空间/动作锚点
```

没有揭示、压迫、贴近人物立场、关系重组或转场需求时，选择**固定机位**。固定镜头也要说明画面内由谁/什么承担变化，例如人物距离、手部接触、呼吸、风、帘子或环境声。

## Camera Zone，不是固定机位点

把场景机位规划理解为合法摄影区域与基础观看方向：`CAM-ZONE-A` 表示摄影机在同一已建立 `Location + View` 和工作侧内可以前后左右、升降、改变焦段/景别、使用过肩、前景遮挡与小幅角度，而不是永远复刻一个坐标和构图。Camera Zone 不是资产，也不替代新 View；门内/门外、越轴后的另一侧或新露出空间仍需对应的 `Location + View`。

每个 Shot 同时设计 `Foreground / Subject / Background`。层次可为空，但不能默认永远是“背景墙 + 中央站立人物”：前景可用门框、肩部剪影、控制台边缘或设备遮挡组织注意力；后景只保留已建立的地标和信息。改变层次不能移动门窗、固定设备或主光。

相邻 Shot 除非导演明确选择有目的的固定覆盖，通常让以下三项至少两项产生可读变化：`Camera`（景别、焦段、机高、角度、构图、层次或运动）、`Body`（姿态、重心、肢体、视线或动作阶段）、`Information`（新事实、反应、权力或结果）。不是为了机械凑变化；若没有新的观看任务，应合并 Shot。

## 基础手法与叙事用途

| 目的 | 优先手法 | 写法与边界 |
| --- | --- | --- |
| 等待决定、沉默、仪式感、让调度自身改变关系 | 固定机位 / `Static Shot` | 写明景别、机位、轴线侧和画内仍在变化的对象；不把空白的“静止”交给模型自由漂移。 |
| 发现证据、逼近真相、压力缓慢收紧 | 推近 / `Push In` | 从可读的起始关系缓慢接近脸、手或证据，在发现/接触/反应处停止。证据不在脸上时，不因情绪而盲目推脸。 |
| 人物渺小、关系拉开、余波、揭示后留白 | 后拉 / `Pull Out` | 从人物或物件后撤到更宽的空间关系，在孤立感、地理或后果成立时停住。 |
| 新信息进入视野、人物把注意转到门/证据/威胁 | 横摇 / `Pan`，俯仰 / `Tilt` | 写清从哪里向哪里、什么动作触发、被揭示对象和停住位置；不是另一个场景的跳切。 |
| 绕开前景遮挡、展示既有空间层次 | 横移 / `Truck`，升降 / `Pedestal` | 仅在当前 `Location + View` 已建立的空间中移动；不得越墙、跨未建立地理或重置入口/出口关系。 |
| 进入、逃离、追赶、人物移动本身承载策略 | 跟拍 / `Tracking Shot` | 跟随明确的行进、转身或接近，保留屏幕方向、目的地和动作终点。 |
| 对峙、围困、权力反转、必须看见另一侧关系 | 短弧环绕 / `Arc Shot` | 沿人物或双人关系绕到新侧面后停止；不默认做无意义 360° 绕圈。 |
| 同一构图内把注意力从人物转给证据、威胁或另一角色 | 拉焦切换 / `Rack Focus` | 写清起始焦点、触发、焦点移动方向和最终落点；景别与空间不变，只有观众注意对象改变。不得用失焦掩盖主体或身份。 |
| 观众必须与角色同知、同样受限或先于角色发现 | 第一视角 / `POV` | 写清是谁在看、此刻能看到什么、必须藏住什么。若 POV 要移动，另写随脚步/转头的移动方式。 |
| 明确选择的手持风格或主观失衡 | 受控轻手持 / `Shake Slightly`（例外） | 写清采用理由、幅度、适用 Shot/时段和恢复方式；普通紧张戏仍优先稳定构图与表演。 |
| 确需摄影机体现的物理冲击或眩晕 | 短促震动 / `Shake Strongly`、滚转 / `Roll`（例外） | 明确摄影机本身的触发和结束，随后稳定观察后果；物体受力不自动让摄影机受震。 |

`Zoom In/Out` 改变焦距；`Push In/Pull Out` 改变摄影机与主体的空间关系。需要表现空间压缩、背景形状改变时必须明确选择哪一种，不能把二者混写。

## 按场景与类型选择

下表是从场景的叙事任务出发的优先起点，不是强制配方。同一题材可以因人物策略、已建立的空间、信息是否该揭示和项目视觉语言而选择不同手法。

| 场景 / 类型 | 优先镜头方法 | 最佳效果 | 避免 |
| --- | --- | --- | --- |
| 开场钩子、人物立即进入事件 | 跟拍主体动作；随后用宽一些的固定或缓慢横摇建立空间 | 先让观众知道“谁在动”，再知道“身处哪里、有什么问题” | 用静物特写或空场长停顿开场，除非静物本身就是已批准的异常/威胁。 |
| 悬疑探查、发现线索 | 固定等待、缓慢推近、横摇/俯仰揭示、受限 POV | 控制观众何时看见证据，放大“看见了但还不理解” | 一开始就用全景或环绕把答案和空间秘密全部给出。 |
| 恐怖、异常降临、心理压迫 | 固定机位与负空间、缓慢推近、延迟横摇、POV；冲击瞬间才短促晃动/滚转 | 让威胁进入已稳定的正常空间，制造等待与失衡 | 从头到尾手持、强晃、滚转或频繁特写，导致信息和恐惧都不可读。 |
| 双人对峙、审讯、谈判、关系破裂 | 以稳定中景/越肩或固定机位保住距离；在权力或信息真正反转时短推、换侧或短弧绕行 | 让谁占入口、谁退让、谁先移动成为画面事实 | 机械正反打、每句台词推近，或无理由 360° 绕人。 |
| 亲密、告白、和解、脆弱时刻 | 稳定近景/中近景、克制缓推、跟随一次靠近或递交后的反应 | 保留呼吸、眼神、手部接触和停顿 | 强手持、过快摇扫、夸张变焦抢走表演。 |
| 追逐、逃离、潜入、寻找出口 | 跟拍、侧向横移、动作方向的横摇/俯仰；已有简单路径时穿梭运镜 | 给清楚的移动方向、目的地与阻碍，让速度来自人物行动 | 复杂长镜头穿墙、多人各自大动作，或用镜头晃动代替真正位移。 |
| 脚步、车轮、拖动物、地面线索或攻击轨迹 | 贴地跟拍 / 低位路径镜头 | 用接近地面的稳定低机位沿已建立路径跟随，在目标接触、停步或危险逼近处落稳 | 未建立路径时自由穿行；把低机位误写成持续晃动；为了速度丢失人物方向和道具归属。 |
| 动作冲突、夺取、递交、开门、接触 | 固定或短跟拍，把起势、接触、结果读清；必要时按动作边界切开 | 保住手、道具归属、身体重心和后果 | 用快速环绕、晃动或长推镜遮住接触点；过程读不清时按准备、接触、结果拆成多个 Shot。 |
| 身份揭示、空间反转、关键证据亮相 | 横摇/俯仰到证据、前景遮挡后的穿入、短推到反应；必要时先受限 POV 再切接收者 | 形成“尚未看到 → 看到 → 理解/受冲击”的明确顺序 | 把揭示和反应挤在同一模糊移动里，或提前展示留给后镜的信息。 |
| 权力翻转、被围困、立场变化 | 改变机位高度/角度与构图占比；短弧环绕或人物位移后的稳定落点 | 让观众看见谁获得空间、谁被堵住、谁失去退路 | 只给角色脸部特写而不展示距离、入口、阻挡或体量关系。 |
| 孤独、后果、失败后的余波、世界尺度 | 后拉、保持宽景固定、缓慢升高或让人物离开画面 | 从人物/物件扩展到其无法掌控的空间与余韵 | 立刻切走或用无关环境特效填满留白。 |
| 城市、宗门、战场、废土或大型路线的空间建立 | 高空建立 / 航拍式覆盖 | 从已建立地理的高空宽景下降、推进或横移，明确人物、入口、路线和主要地标的关系 | 没有 Scene Bible/场景板便让模型补造城市；从室内无因升到屋外；炫耀尺度却不交代行动方向。 |
| 喜剧反应、尴尬、信息错位 | 稳定双人/群像构图、短横摇到反应者、必要时有节奏的快速摇扫 | 让反应、停顿和空间关系成为笑点 | 长时间手持、随机推拉或把每个反应拆成炫技镜头。 |
| 纯环境、道具、机制或功能展示 | 固定构图、受控横移/俯仰、短推到可验证细节 | 让观众看清结构、材质、尺度、工作方式或空间地理 | 虚构人物冲突、无依据的环境灾害，或用夸张运动遮住关键细节。 |

### 题材只给倾向，不覆盖场景目的

- **悬疑 / SCP / 克苏鲁**：优先控制“看见的范围”与“揭示触发”。固定、负空间、受限 POV 和延迟揭示通常比持续晃动更有效。
- **公路 / 探险 / 废土**：优先让人物移动与广阔空间形成关系；跟拍、横移、后拉、明确地标和屏幕方向比随机环绕更重要。
- **情感 / 节日短片**：优先人物之间的距离、递交、靠近、停顿与反应；稳定构图和克制推近通常优于快速剪切。
- **动作 / 惊悚追逃**：优先清楚的方向、目标、阻碍与接触结果；镜头可以更活，但不能牺牲道具归属和空间可读性。

当同一场景同时满足多个类型时，以本 Shot 最需要观众读到的**动作、信息或关系变化**为准，而不是题材标签。例如恐怖片中的递交物件，仍先保证手部接触与物权变化；情感片中的身份揭示，仍先按揭示顺序设计镜头。

## 组合与高级手法

组合手法必须有阶段，不得在同一瞬间竞争：

- **摇扫推进**：先向信息源快速横摇/扫过；在发现或定格的触发点转为短促推近，停在脸、手或证据。它服务“搜索 → 锁定”，不是任意 `Pan + Push In` 叠加。
- **穿梭运镜**：摄影机从明确的前景遮挡物、门框或走廊边穿入，沿已建立且可行的路径前进/横移，在人物、证据或新空间前停下。只用于已有 `Location + View` 能证明的简单路径；禁止穿墙、穿人、穿过未建立空间。
- **遮挡转场 / 前景擦镜**：让场内真实存在的门框、柱子、人物肩背、车辆或暗部沿明确方向短暂遮满画面，再在下一 Shot 从匹配方向揭开。它服务同场换机位、进出空间或路径衔接；遮挡前后的身份、位置、持物、屏幕方向和光声状态仍须连续，不能用黑场遮住瞬移或道具消失。
- **甩镜转场 / Whip Pan Transition**：上一 Shot 因可见动作、突发声音或注意力转移向明确方向快速甩出，下一 Shot 从同方向、相近速度的运动模糊中进入并迅速稳定在新目标。写清触发、甩动方向、切点和稳定落点；不把甩镜扩散成整段手持，也不用于修补不兼容的地理或人物状态。
- **希区柯克变焦 / Dolly Zoom**：摄影机前移或后撤，同时反向变焦，使背景出现受控的透视拉伸。只服务突发失衡、恐惧认知或世界感崩塌；它不是普通推近。当前 H3 路线未把它列为已验证的基础词，只有在该效果是已批准的核心视觉 Beat 且当前模型版本已有成功小样时才选用；否则用推近、后拉、构图/光线变化表达同一戏剧功能。

### 焦点、转场与特殊机位的职责

- **拉焦切换**改变同一构图中的清晰注意对象，不自动建立新 Shot。焦点从 A 转到 B 必须由视线、声音、动作或信息出现触发；如果必须改变观察立场或空间关系，则建立新 Shot，而不是用拉焦代替覆盖。
- **遮挡转场和甩镜转场**是两个 Shot 之间的连接方式，不是独立剧情 Shot。两端先各自满足 Beat、动作与状态合同，再设计匹配方向和切点；转场特效不能修复错误的上一末态或下一开场。
- **高空建立和贴地跟拍**是机位高度、路径与覆盖的组合。前者必须有已建立的大尺度地理，后者必须有可行的地面路径；两者都继承当前轴线、屏幕方向、地标、道具和主光。

荷兰角、快速甩镜和多圈环绕同属强调效果。它们只在视角/重心/注意力确实突变时按需使用，不能成为悬疑或高潮的默认装饰。

## H3 直译词与提示词写法

下列基础词可按当前 H3 语义写为自然语言：`Static Shot`、`Push In`、`Pull Out`、`Zoom In/Out`、`Pan Left/Right`、`Tilt Up/Down`、`Truck Left/Right`、`Pedestal Up/Down`、`Arc Shot`、`Tracking Shot`、`Shake Slightly/Strongly`、`POV`、`Roll Clockwise/Counterclockwise`。拉焦、贴地跟拍、高空建立、遮挡转场和甩镜转场优先写成完整自然语言过程，不依赖单独英文名让模型猜测起点、方向、切点或落点。

最终 H3 文本不要只放一个镜头名。至少写出：起始关系、何时因何动作开始、方向/速度、跟随或揭示的对象、结束构图。例如：

```text
钥匙落在桌面后，摄影机从稳定的双人构图沿短轨道平滑推近手与钥匙，
保持水平线稳定，在细节清楚时柔和减速并停稳；人物继续完成收手和观察的动作。
```

跟拍示例：摄影机以稳定器平稳跟随人物走向门口，保持已设计的相对距离和水平线，在人物停步时柔和减速，停在侧面中景。演员的喘息与衣服摆动属于身体表演，不改变相机的稳定支撑。

提交前静默检查：若正文只写“跟拍/缓推/POV”而没有稳定性信息，补成上述可见的平稳摄影目标。检查局部手持或震动是否明确限于所选镜头，普通镜头是否恢复稳定；这不是关键词禁用检查，“手持道具”和“物体震动”不能误判成摄影机抖动。

每个 Shot 默认一个主导摄影行为。只有摇扫推进、明确的固定→移动过渡等确有连续因果的组合，才分阶段写清；真实硬切、明显换机位或第二个独立摄影意图在分镜导演板中拆为多个 Shot，并以递增切点交给 H3；跨 Clip 后才由必剪连接。

## 不可破坏项

- 摄影机移动不能改写已建立的 `Location + View`、入口/出口、工作侧、轴线、屏幕方向、地标、道具归属或主光。
- 不能用运镜掩盖复杂交接、夺取、开门或追逐的过程；过程本身读不清时，按起势/接触/结果或真实剪辑点拆多个 Shot。
- 不要把每次情绪升级写成慢推近，也不要让每个对白变成机械正反打；信息在哪里、谁接收后果、空间关系如何变化，才决定镜头。
- 同一 `Location + View` 或 Camera Zone 不等于同一景别、机高、焦段、主体位置和前中后景。连续多个 Shot 复刻这些内容且没有明确固定覆盖理由，属于摄影设计失败。
- 环境微动只保留有剧情或物理依据的风、布料、蒸汽、机械、尘埃、光影和声音响应，不凭空添加天气、火、群众或事故。

生成后按真实媒体 QA 检查：摄影是否让关键事件可读、是否遮掉脆弱锚点、是否与表演和声音同步、是否漂移或破坏空间。失败时只修实际对应 Shot 的 `camera_contract`、目标 Panel 或输入问题，不用更多镜头术语掩盖缺陷。
