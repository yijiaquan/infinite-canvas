# 共情、冲突、反差与价值转折

## 1. 共情不是讨喜

观众可以共情一个并不善良的人，只要能读懂他在保护什么、害怕失去什么，以及为什么会作出当前选择。优先使用四种可见载体：

- 具体需求：钱、时间、安全、身份、关系、尊严或答案；
- 保护行为：主角主动保护的人、承诺、秘密或生活秩序；
- 能力与缺口：一项真正有用的能力，加上一项会制造错误选择的盲区；
- 代价选择：主角愿意为目标付出什么，又拒绝牺牲什么。

避免用悲惨身世、哭泣或旁白直接替代共情。先让观众看见人物怎样行动，再让背景解释行动为何重要。

## 2. 冲突是反制，不是争吵

冲突成立需要四项：双方目标不兼容、双方都有行动能力、每次行动遭遇具体反制、失败会改变处境。对手不必是反派，也可以是制度、时间、关系、环境或主角自身的惯常策略。

递进复杂化优先改变以下任一项：

- 成本更高；
- 时间更少；
- 可选方案更少；
- 暴露范围更大；
- 关系更私人；
- 新事实使旧策略失效；
- 成功会同时伤害另一项重要价值。

只把动作做得更大、敌人变得更多，不等于冲突升级。

## 3. 反差必须参与因果

可用反差包括：

- 身份反差：最不该做这件事的人被迫承担它；
- 性格反差：冷酷者保护弱者，胆小者最先行动，但必须有角色理由；
- 处境反差：庄严任务发生在低俗、琐碎或失控的现实中；
- 认知反差：角色确信的解释与观众逐渐看见的事实不同；
- 结果反差：越努力修复，越把局面推向相反结果；
- 情绪反差：喜庆表面承载悲剧，危险处境中出现克制幽默。

反差至少需要在后续造成一次选择、误判、关系变化或代价，否则只是包装。

## 4. 价值转折与预期落差

主要场景或 Beat 应发生价值变化，例如：

```text
安全 -> 暴露
信任 -> 怀疑
控制 -> 失控
孤立 -> 暂时结盟
希望 -> 带代价的希望
无知 -> 知道了却无法退出
```

好的转折通常经历：

```text
角色采取行动
-> 现实产生与预期不同的反应
-> 新事实或反制出现
-> 角色必须调整策略或作出选择
-> 价值状态改变
```

如果删除一个 Beat 后，人物策略、代价、信息或关系没有变化，该 Beat 多半只是气氛或重复说明。

### 场景价值转变

场景不是由地点、出场人物或一段对白定义，而是由一次完整的价值变化定义。进入和离开场景时，至少一个主要价值域必须不同：

```text
一方垄断规则 -> 另一方公开挑战规则
礼貌协商 -> 暴力成为可用选项
表面让步 -> 重新夺回解释权
安全旁观 -> 被迫成为参与者
```

先写场景开头谁拥有什么、相信什么、能决定什么，再写结尾这些条件怎样变化。对白、动作和道具都应推动这次变化；如果场景结束后一切仍与开头相同，就应合并、删减或重写。

## 5. 从诱发事件到结局

- 诱发事件：打破主角原有平衡，并产生无法长期忽略的问题；
- 递进复杂化：主角用惯常策略解决问题，现实不断扩大策略缺陷；
- 中点变化：目标、理解、关系或行动方式发生实质变化；
- 危机：两个选项都要求牺牲重要价值，不能靠第三个免费选项逃脱；
- 高潮：主角作出最能定义人物的不可撤销行动；
- 结局：展示选择造成的新现实，而不是用解释复述主题。

故事命题可写成：`某种价值最终成立或崩塌，因为主角在压力下采取了某种行动。` 它是写作判断，不应变成角色口中的主题演讲。
