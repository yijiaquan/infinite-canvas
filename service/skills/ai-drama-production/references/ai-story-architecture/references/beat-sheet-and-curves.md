# 功能节拍、场景价值与双曲线

本页用于短片、单集或故事架构不清时的诊断。借鉴功能节拍思路检查故事职责是否完整，但不要求固定 15 个节拍、固定页码、固定时点或机械套用名称。

## 功能节拍

短片通常从以下功能中选择真正需要的部分，并可合并相邻功能：

| 功能 | 要解决的问题 |
|---|---|
| 开场画面 | 故事开始时，谁掌握局面，世界处于什么价值状态？ |
| 主题暗示 | 哪个行为、矛盾或选择让主题开始可见，而不是由角色讲道理？ |
| 诱发 / 催化 | 什么事件打破平衡，使主角不能继续维持原状？ |
| 争执 / 反应 | 主角为什么抗拒、误判或继续使用旧策略？ |
| 进入主要冲突 | 哪个选择让人物真正进入无法轻易退出的局面？ |
| 递进复杂化 | 对抗如何缩小选择、提高代价或改变规则？ |
| 中点变化 | 权力、目标、理解、时间压力或关系发生了什么实质反转？ |
| 压力逼近 | 对手、制度、后果或人物盲区如何同时收紧？ |
| 失去旧方案 | 哪个结果证明原有策略已经失败？ |
| 危机与选择 | 哪两个真实选项都要求牺牲重要价值？ |
| 高潮行动 | 主角采取什么不可撤销行动定义了自己？ |
| 结尾回声 | 结尾画面如何展示新现实，并与开场形成变化或反讽？ |

同一个 Beat 可以承担多个功能。极短片可以只保留开场、催化、升级、中点、危机、高潮和结尾；较长故事可以展开。判断标准是故事功能是否完成，不是标签是否齐全。

## 场景价值表

对每个完整场景填写：

| Scene | 开头价值状态 | 角色行动 / 对抗 | 预期与现实落差 | 结尾价值状态 | 下一场为何发生 |
|---|---|---|---|---|---|

价值状态优先使用具体关系：谁掌握钱、规则、武器、信息、退路、信任或解释权。不要只写“平静 -> 紧张”，那属于情绪变化，不足以证明剧情发生了变化。

## 故事曲线与情绪曲线

故事曲线记录发生了什么：

```text
提出分配 -> 质疑规则 -> 暴力进入桌面 -> 表面让步
-> 新诱惑改变规则 -> 人物离开 -> 代价落在旁观者 -> 空场余波
```

情绪曲线记录观众怎样感受：

```text
压迫 -> 紧张上升 -> 荒诞突变 -> 短暂冷却 -> 不安回流 -> 冷峻余韵
```

检查两条曲线：

- 每个主要事件是否改变情绪或重新解释之前的情绪；
- 每次情绪峰值是否来自行动、信息或代价，而不是形容词；
- 是否存在必要的冷却、停顿或反差，使下一次升级更有力量；
- 结尾情绪是否由结局事实产生，而不是旁白宣布；
- 故事曲线重复但情绪不变时，合并事件；情绪剧烈变化但没有事件依据时，补足触发和后果。

## 黑色幽默短片示意

一个围绕规则、暴力、公平与诱惑的三段式短片，可以这样使用功能节拍：

```text
第一段：利益出现 -> 掌权者定义公平 -> 另一人质疑分配权
第二段：暴力成为筹码 -> 掌权者表面让步 -> 用新诱惑重写游戏规则
第三段：人物离场 -> 无辜旁观者承受荒诞后果 -> 空场保留反讽
```

这里真正的价值变化不是“谈话变激烈”，而是：

```text
单方面掌控 -> 权力受到挑战
武力威胁 -> 规则操纵重新占优
人物自以为完成交易 -> 世界展示交易的真实代价
```

具体角色、动物、道具和地点由当前项目决定；示意只保留结构功能。
