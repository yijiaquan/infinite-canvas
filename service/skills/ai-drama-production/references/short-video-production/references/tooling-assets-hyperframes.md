# HyperFrames 信息图与覆盖层

只在需要可编辑的地图、时间线、数据卡、关系图、章节卡、引用说明或品牌覆盖层时读取。HyperFrames 是确定性 HTML/CSS/JS 合成工具，不生成故事图像或视频，也不能冒充事实影像。

## 何时使用

- 用于解释、标注和信息设计；真实证据仍用有权利的来源，故事画面仍用已选素材或 ComfyUI。
- 每个覆盖层先写清它帮助观众理解什么，避免遮住角色、字幕和关键动作。
- 不需要为普通字幕、简单标题或纯装饰启动 HyperFrames。

## 当前项目落盘

```text
项目/<项目名>/
├─ 必剪/HyperFrames/     # HTML/CSS/JS、预览和输入说明
├─ ComfyUI输出/             # 只放 ComfyUI 原始请求与输出
└─ 媒体/视频/ 或 媒体/音频/ # QA 后采用的可导入渲染文件
```

项目专属输入素材必须已有权利依据。生成的覆盖层先保留源文件和预览；原始导出在确认可用于时间线后登记为持久参考媒体并导出供必剪使用，不冒充角色、场景或 Voice 资产。

## 最小工作法

1. 设计单一观众任务和目标画幅/安全区。
2. 在 `必剪/HyperFrames/` 制作可编辑源文件，记录数据或素材来源。
3. 预览文字可读性、溢出、节奏和对画面的遮挡；透明层确认目标编辑器能保留 alpha。
4. 导入必剪实际时间线检查合成效果；通过后采用渲染文件，保留源文件以便后续改字或改节奏。

不要把覆盖层当成生成视频、图片或真实事件证据；导出与整片审核仍由 Short Skill 负责。
