# 开头五秒与观看动力

开头目标是在不误导观众的前提下，尽快给出一个清楚的问题、变化、风险、反差或行动。它是创作判断，不是额外文件、编号、审批或生成前置条件。

## 选择一个主要机制

| 机制 | 开头可见内容 | 后续必须兑现 |
|---|---|---|
| 结果先出 | 已造成的后果 | 原因与代价 |
| 行动已开始 | 人物正在应对压力 | 目标与阻力 |
| 观众先知道 | 人物还没发现的威胁或事实 | 发现或危险升级 |
| 异常细节 | 与常识冲突的一项证据 | 它是线索、规则或后果 |
| 被迫选择 | 两个都要付代价的选项 | 选择或代价升级 |
| 反应先出 | 一个具体反应，原因暂时隐藏 | 原因在情绪失效前揭开 |
| 规则被破坏 | 已知秩序被打破 | 谁发现、改变什么 |
| 承诺或演示 | 观众会得到的明确回报 | 真正交付该回报 |

可叠加一项不抢注意力的次机制。不要用无关奇观、倒计时、喊叫或只靠旁白的“你绝对想不到”代替故事。

## 五秒内的设计检查

1. 立即让主体、压力或异常可见；静音播放时仍能理解核心问题。
2. 让观众的问题具体化，并给出一项证据、限制或反应。
3. 到约五秒时，信息、情绪、权力、风险、关系或物理状态至少有一项改变。
4. 后续 Beat 必须回答或转化这个问题，不能让标题、开头与真实故事脱节。

发布后如果主人要求复盘，再使用平台已有的首段留存、平均观看或完播数据；保留平台原始指标名称，不把不同时间口径伪装成同一个“五秒率”。
